# 决策记录：MR 指标废弃

_生效：2026-10-20（evaluator 移除计算）／2026-10-21（决策确认并成文）_

## 1. 决策

**MR（Miss Rate）从 TrajGap-Bench 主榜指标中废弃。**

- `evaluate_predictions` 不再计算 MR（`src/evaluation/trajimpute_direct.py`，2026-10-20 20:48 移除）；
- 主表指标固定为四项：`minADE20`、`minFDE20`、`ADE@1`、`FDE@1`；
- 每项必须**同时给出宏平均（五场景等权）与样本加权**两个口径；
- 训练期 `val_MR` 保留为诊断量写入 `metrics.csv`，**不作为选点依据**（选点统一为 `val_new_minFDE20`）。

## 2. 废弃理由

### 2.1 阈值二值化丢失信息

MR 定义：全部 K 条候选的终点误差都 > 2.0 m 才算一次 miss。

```
MR = mean( (fde > 2.0).all(-1) )  ≡  mean( min_fde > 2.0 )
```

它是 `minFDE20` 在固定阈值上的二值化。误差 2.1 m 与 10 m 在 MR 里完全等价，因此它无法区分"略微越线"与"彻底失败"。

### 2.2 宏平均被最小场景主导（决定性理由）

ETH-M 只占 **0.54%** 的测试样本（1,629 / 302,886），却占宏平均 **20%** 的权重。

实测后果（`docs/results/stage_dap.md`）：

| 方法 | 宏平均 MR | 样本加权 MR |
| --- | ---: | ---: |
| GAST-PF-DAP | **4.43%（宏平均最优）** | 3.42% |
| FrameGeo | 5.15% | 2.94% |
| MoFlow | 4.60% | **2.78%（样本加权最优）** |
| AnchorGeo | 4.86% | 3.03% |
| MRT | 4.78% | 3.07% |

同一个方法在两个口径下的排名完全相反。DAP 在 ETH-M 上领先 4.5 个百分点，压过了它在其余四个场景对 MoFlow 的全部劣势。

**一个 0.54% 样本的场景能翻转全局排名，说明该指标的宏平均不可用于方法比较。**

### 2.3 小场景二项噪声过大

MR 是二值指标的均值，服从二项分布，标准误 `sqrt(p(1-p)/n)`：

| 场景 | n | MR 量级 | 1 SE |
| --- | ---: | ---: | ---: |
| ETH-M | 1,629 | 11% | **±0.78 pp** |
| HOTEL-M | 9,477 | 4% | ±0.21 pp |
| UNIV-M | 219,006 | 4% | ±0.04 pp |

ETH-M 的一个标准误比多数方法间的差距还大。实际检验中，DAP 相对 MoFlow 的 MR 优势为 −0.16 pp、合并 SE 0.24 pp，**|Δ|/SE = 0.68，属噪声**。

### 2.4 阈值与场景尺度不匹配

阈值固定 2.0 m，但各场景未来位移尺度差异很大：HOTEL-M 均值 1.91 m、ZARA1-M 4.23 m、ETH-M 4.35 m。在 HOTEL-M 上该阈值几乎不触发（MR 全部挤在 3.6–4.4%），指标饱和、无分辨力。

## 3. 替代方案

| 原用途 | 替代 |
| --- | --- |
| 覆盖能力（正确答案在不在 20 条候选里） | `minFDE20`（连续，含全部信息） |
| 灾难性失败频率 | `minFDE20` 的高分位（如 P90/P95），或按 `anchor_lag` 分层看长缺失段 |
| 排序质量 | `ADE@1` / `FDE@1`（不变） |

若后续确需一个"漏检率"类指标，必须满足：**样本加权口径**、按场景尺度归一化、并在小场景上报告置信区间。当前不引入新指标。

## 4. 历史结果的处理

- 2026-10-20 之前产出的 `results.json` 保留原始 MR 值，作为**历史记录**；
- 这些 MR 值**不得用于新的方法比较或论文结论**；
- 不重算历史 MR——重算需要重新跑评估，而指标本身已废弃，无此必要；
- 引用历史结果时须标注"MR 已废弃，仅存档"。
