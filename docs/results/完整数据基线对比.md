# 完整数据基线（无缺失）

> 初始 M0 对比：2026-08-27（ETH/UCY）/ 2026-08-29（SDD）；当前 `GAST` clean 重训：2026-10-28。数值明细：[完整数据基线数据.csv](完整数据基线数据.csv)

## 评估协议

- 数据：ETH/UCY 五折留一（LOO），8 帧历史 → 12 帧未来，米制；SDD 使用 `sdd_train/sdd_test.pkl`，train/val = 90/10，seed 2024，像素制。
- 初始 M0 Clean：报告 minADE20 / minFDE20，按 `val_minFDE20` 选点。
- 当前 GAST Clean：报告 minADE20 / minFDE20 为主指标，ADE@1 / FDE@1 为辅助指标；按 `val_new_minFDE20` 选点。
- 每个 ETH/UCY fold 的目标场景仅用于 test，其余四场景用于 train/val；验证宏平均与 held-out 测试宏平均不是同一批场景的配对比较。
- 结果仅报告本文模型与公开 SOTA 参考，不进行教师模型或其他指定模型的比较。

## 当前 GAST Clean 结果

当前 GAST 使用 canonical ETH/UCY LOO 协议，8 帧历史预测 12 帧未来，`K=20`，seed 2024，100 epochs，并按最终预测头 `val_new_minFDE20` 选择 checkpoint。测试使用无缺失的原始 ETH/UCY held-out split，所有误差单位为米。

| **样本加权平均** | **33,654** | — | **0.2024** | **0.3648** | **0.6111** | **1.3078** |

与最初 M0 Clean 基线（`0.232/0.389`）相比，当前 `GAST` 的宏平均 `minADE20` 降低约 2.5%，`minFDE20` 上升约 1.0%，因此不能宣称在 clean benchmark 上全面超过初始 M0。相对于 seed 2025 的 M0 重训结果（`0.240/0.431`），当前模型的 `minADE20/minFDE20` 分别降低约 5.6%/9.0%；该比较受 ETH 小场景种子方差影响，只作为稳定性参考，不作为独立方法贡献的因果证据。

ETH 是当前 clean 测试的主要短板：其 `minADE20=0.4670`、`minFDE20=0.8135`，明显高于其他场景。验证宏平均为 `0.1712/0.3026`，测试宏平均为 `0.2260/0.3927`；由于每折验证集来自其余四个场景，这一差异反映 held-out 场景域偏移，不能直接解释为常规同分布过拟合。

## 一句话结论

项目最初的无缺失 M0 基线为 `0.232/0.389`；当前 `GAST` 在同类 clean LOO 协议下为 `0.226/0.393`，说明完整历史输入下性能基本保持，但主要优势仍应由缺失历史 TrajGap-Bench 实验来证明。SDD 结果仍为 `8.31/13.66`。
