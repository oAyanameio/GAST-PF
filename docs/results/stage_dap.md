# GAST-PF-DAP · Directional Attention Pooling

_接在 Stage 2 之后的读出层探索；不属于路线文档预注册的 Stage 序列_

> **MR 已废弃（2026-10-20）**：本文件中的 MR 数值为历史记录，仅作存档，**不得用于新的方法比较或论文结论**。废弃理由与替代口径见 `docs/results/MR废弃决策.md`。当前主表指标为 minADE20 / minFDE20 / ADE@1 / FDE@1，且须同时给出宏平均与样本加权。

## 1. 动机与实现

原 GAST-PF 固定读**最后一个时间步**的时序状态。当末端观测缺失时，这个位置读到的是 gap-filled 的占位状态，读出会退化。

DAP 改成把**前向与后向两条时序状态一起做注意力池化**，池化权重由一个 4 维门控决定：

| 门控输入 | 含义 |
| --- | --- |
| `left_ratio` / `right_ratio` | 历史前半段 / 后半段的观测有效率 |
| `terminal_missing` | 末帧是否缺失 |
| `max_run` | 最长连续缺失段（按 `obs_len` 归一化） |

实现：`DirectionalAttentionReadout`（`src/model/layers/gast_encoder.py`），开关 `gast_directional_readout`，默认关闭。

**参数量**

| 模型 | 总参数 | 增量 |
| --- | ---: | ---: |
| GAST-PF | 5,213,968 | — |
| **GAST-PF-DAP** | 5,218,611 | **+4,643（+0.089%）** |

保持不动：GSM 空间注意力、Temporal Decay、双向 Mamba、decoder、loss、TrajGap 协议。

## 2. 协议

TrajGap-Bench Mixed-direct；seed=2024；K=20；100 epochs；batch size=64；选点 `val_new_minFDE20`；`experiment_class=screening`（单种子）。样本合计 302,886。

训练：2026-10-19 18:50 → 2026-10-20 18:49。`LAPLACE_LOSS_IMPL=vectorized-batch-v1`。全程 `Traceback=0 / CUDA错误=0 / OOM=0`。

> 训练期间做过一次迁卡：GPU 2 被三人共享后速率降至 116.6 step/min，ZARA2-M 从 e56 迁回 GPU 3 续训，恢复 162.4 step/min。

## 4. 关键口径问题：宏平均 MR 被最小场景主导

| 方法 | 宏平均 MR | **样本加权 MR** | ETH-M MR | ETH-M 样本占比 |
| --- | ---: | ---: | ---: | ---: |
| **DAP** | **4.43%（最优）** | 3.42% | 11.05% | 0.54% |
| GAST-PF | 4.50% | 3.16% | 11.91% | 0.54% |
| MoFlow | 4.60% | **2.78%（最优）** | 14.30% | 0.54% |
| M0 | 4.67% | 3.72% | 11.97% | 0.54% |
| MRT | 4.78% | 3.07% | 13.32% | 0.54% |
| AnchorGeo | 4.86% | 3.03% | 14.49% | 0.54% |
| FrameGeo | 5.15% | 2.94% | 15.53% | 0.54% |
| SocialLSTM | 6.01% | 4.36% | 15.84% | 0.54% |

ETH-M 只占 **0.54%** 的样本，却占宏平均 **20%** 的权重。DAP 在 ETH-M 的 MR 领先 4.5pp，压过了它在其余四个场景对 MoFlow 的全部劣势。

逐场景 MR（DAP vs MoFlow）：ETH-M 胜，HOTEL-M / UNIV-M / ZARA1-M / ZARA2-M **全部负**。

**结论：DAP 的「宏平均 MR 全场最优」是聚合口径造成的假象，不能作为 MR 优势主张。** 样本加权下 DAP 的 MR 反而劣于 MoFlow（3.42% vs 2.78%）、FrameGeo（2.94%）、AnchorGeo（3.03%）、MRT（3.07%）。

## 5. 机制检验：否证

若「按缺失模式自适应选向」成立，收益应集中在 `terminal_missing=true` 与长 `anchor_lag`。实测（样本加权，对照 FrameGeo）：

| 分组 | minFDE20 Δ | MR Δ |
| --- | ---: | ---: |
| `terminal_missing=true`（n=135,417） | **+3.75%** | **+18.74%** |
| `terminal_missing=false`（n=167,469） | +2.61% | +8.09% |

对照 MRT（五场景齐备）按 `anchor_lag` 分层，MR 在**每一个桶上都更差**：

| anchor_lag | n | DAP MR | MRT MR | ΔMR |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 167,469 | 1.22% | 1.07% | +13.67% |
| 1 | 60,284 | 2.24% | 1.90% | +17.96% |
| 2 | 30,263 | 4.07% | 3.41% | +19.26% |
| 3 | 17,368 | 6.55% | 5.80% | +12.80% |
| 4 | 10,763 | 10.61% | 8.99% | +17.98% |
| 5 | 7,379 | 14.92% | 14.76% | +1.10% |

**机制最该帮到的组退化最大，且无随缺失加重而改善的剂量-效应。**

## 6. 梯度证据（补充）

用 `scripts/审计与校验/probe_gradients.py`（4 batch、关闭 dropout/drop-path）对比 DAP 与基础版：

| 模块 | DAP | GAST-PF | 比值 |
| --- | ---: | ---: | ---: |
| `enc.spatial` | 11.6 | 576.0 | **0.02×** |
| `enc.temporal` | 21.2 | 60.0 | 0.35× |
| `enc.readout`（DAP 新增） | 5.8 | N/A | — |
| `decoder` | 3564.5 | 4010.5 | 0.89× |

`patch_embed.0.weight` 梯度：DAP 11.58 vs 基线 575.09，**相差 50 倍**。编码器占总梯度比例从约 1% 降到 0.1%。

注意力池化在时间维做了平滑平均，反向传回输入层的梯度被大幅削弱。这与「DAP 只在 ETH-M 有优势、在大样本场景无优势」的形态一致。

> 方法学注意：首轮探针用 2 个 batch 且 drop-path 开启，结论完全相反（DAP 强 46 倍）。drop-path 随机丢整条残差分支，会让单 batch 梯度失真，**梯度对比必须多 batch 平均并关闭随机失活**。

## 7. 判定

**机制层面：No-Go。** 依据：

| 依据 | 证据 |
| --- | --- |
| 机制分层否证 | `terminal_missing=true` 组 minFDE20 +3.75%、MR +18.74%，最该受益的组退化最大 |
| 无剂量-效应 | `anchor_lag` 全部桶 MR 均劣于 MRT |
| MR 优势是口径假象 | 宏平均最优，样本加权劣于四个对照 |
| 对内部基线无优势 | 几何精度落后 M0 2.44%、GAST-PF 1.12% |
| 梯度侧证 | 编码器输入层梯度降至基线 1/50 |

**工程层面：保留为 ETH-M 场景改进。** 依据：

| 依据 | 证据 |
| --- | --- |
| ETH-M 五项全胜 MoFlow 与 SocialLSTM | 0.6108 / 0.8262 / 1.4281 / 2.4263 / 11.05% |
| ETH-M minFDE20 优于 M0 | 0.8262 vs 0.8532（−3.2%） |
| ETH-M MR 优于 M0 | 11.05% vs 11.97%（−7.7%） |
| 对外部模型胜场 | vs MoFlow 20/25、vs SocialLSTM 23/25 |

ETH-M 是缺失最严重、样本最少的场景。DAP 在这里的优势真实，但**不能外推到其余四个场景**。
