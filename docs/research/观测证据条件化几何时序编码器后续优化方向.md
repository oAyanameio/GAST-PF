# 观测证据条件化几何时序编码器：后续优化方向

_研究路线文档 · 2026-10-14 · 面向缺失历史轨迹的行人未来多模态预测_

## 0. 文档定位

本文档用于记录当前 `GAST-PF` 架构后续优化的唯一实施路线，供后续代码 agent 按阶段阅读和实现。本文档只提出方案，不修改代码，也不恢复已经删除或否定的实验分支。

当前工作名称为：

> **观测证据条件化几何时序编码器**  
> **Observation-Conditioned Geometry-Temporal Encoder，简称 OCGT-ENC**

OCGT-ENC 不是把 `UniTraj`、`GSM`、`Temporal Decay` 和双向 `Mamba` 简单拼接，而是围绕一个任务特定问题重新组织这些机制：

> **当历史轨迹存在遮挡、中断或末端缺失时，哪些观测可以作为可靠证据参与空间交互、时间状态传播和最终状态读出？**

后续方法的创新重点应放在“观测证据如何改变信息传播”上，而不是把某个通用模块本身声称为原创。

---

## 1. 当前模型和已确定边界

### 1.1 当前正式模型是 `GAST-PF`

当前新架构由 `TrajectoryForecaster` 通过 `encoder_type` 选择：

```text
encoder_type = m0     -> M0 原始历史编码器
encoder_type = gast   -> GAST-PF 完整替换臂
```

主要代码位置：

| 内容 | 当前文件 |
| --- | --- |
| `GAST-PF` 主体 | `src/model/layers/gast_encoder.py` |
| 编码器选择和 decoder 接口 | `src/model/trajectory_forecaster.py` |
| 历史数据字段、`x_centers`、`x_angles` | `src/datamodule/ethucy_benchmark_dataset.py` |
| 模型开关 | `conf/model/missing_aware_ethucy_model_forecast.yaml` |
| TrajGap 实验入口 | `scripts/训练与评估/run_trajimpute_experiments.py` |

### 1.2 当前 GAST-PF 数据流

当前输入首先在 `TrajectoryForecaster.forward` 中组成四维历史特征：

```text
hist_feat = [x_positions_diff, x_velocity_diff, x_valid_mask]
          = [位移差分 2 维, 速度变化 1 维, 有效性掩码 1 维]
```

张量形状为：

```text
hist_feat       [B, N, T, 4]
valid_mask      [B, N, T]
key_padding     [B, N]
```

随后进入：

```text
逐帧 GSM 空间注意力 + ghost token
        ↓
前向/后向 missing-run delta
        ↓
Temporal Decay：x' = gamma ⊙ x
        ↓
前向 Mamba + 后向 Mamba
        ↓
两个方向输出直接相加
        ↓
固定读取最后时间步 y[:, -1]
        ↓
原有 FutureDistributionDecoder
```

`GAST-PF` 输出仍然是 `[B, N, embed_dim]`，后续 `FutureDistributionDecoder`、loss、指标和 TrajGap-Bench 协议保持不变。

### 1.3 当前借用内容和自有内容的边界

| 机制 | 当前处理 | 后续表述边界 |
| --- | --- | --- |
| GSM 逐帧空间注意力 | 从 UniTraj 借用并适配动态 actor 数量 | 不作为原创；后续改造成缺失感知关系传播 |
| ghost token | 从 UniTraj 借用 | 只承担聚合上下文，不宣称是任务创新 |
| Temporal Decay | 从 UniTraj 借用，当前为 `exp(-ReLU(Linear(delta)))` | 后续改造成任务特定的 evidence-age gate |
| 双向 Mamba | 从 UniTraj 借用，两条独立栈后直接相加 | 后续改造成可靠性加权方向融合 |
| 结构化未来分布 decoder | 原有组件 | 保持不变，作为公平比较接口 |
| TrajGap-Bench | 当前任务协议 | 保持不变，所有阶段统一评测 |
| `x_centers`、角度等几何字段 | 数据层已有，GAST-PF 尚未使用 | 作为后续几何条件化的输入证据 |

以下内容不恢复、不作为后续路线：

- 已删除的 `CondDeltaMamba`；
- 原 ODMR/M0 增量模块及其失败实验分支；
- M1 概率校准路线；
- 重建辅助分支；
- split-conformal 校准；
- UniTraj 的 Future Encoder、CVAE 潜变量和 diverse loss；
- 将原论文完整移植后直接包装为新方法。

### 1.4 当前已暴露的结构问题

1. `GAST-PF` 主要看到位移差分、速度差分和 mask，缺少明确的绝对或相对空间几何。
2. `GAST-PF` 没有使用数据层已有的 `x_centers` 和末端方向信息，也没有显式使用 anchor lag。
3. 当前 GSM 的 `key_padding_mask` 只能屏蔽 padding actor，不能表达“当前帧的缺失 actor 不应作为可靠 key”。
4. 当前 `Temporal Decay` 可能衰减有效帧，不能保证全有效输入时严格保持 `gamma=1`。
5. 当前前向、后向 Mamba 输出直接相加，没有根据两侧观测证据的可靠程度动态融合。
6. 当前固定读取 `y[:, -1]`。当末端存在缺失时，最后时间步存在可靠性风险，但不能据此直接认定读出位置是主要瓶颈；历史实验已经表明，简单替换为 `last-valid` 并不能稳定解决问题。
7. 当前 actor 关系主要由内容注意力隐式学习，没有显式的 focal–neighbor 相对位置、相对运动和方向关系。

### 1.5 当前初步结果的使用方式

已有 ETH-M 初步结果如下，当前只能视为探索性筛选，不足以证明 `GAST-PF` 已经有效：

| 指标 | M0 | GAST-PF |
| --- | ---: | ---: |
| `minADE20` | 0.6145 | 0.6191 |
| `minFDE20` | 0.8532 | 0.8544 |
| `ADE@1` | 1.4034 | 1.4232 |
| `FDE@1` | 2.4877 | 2.4693 |
| `MR` | 11.97% | 11.91% |

结论是：整体基本持平，不能把性能变化归因于任一借用模块。后续必须采用单变量递进和配对实验，先定位几何、缺失传播、方向融合、读出中的真实瓶颈，再决定是否组合。

### 1.6 既有读出实验的边界

项目此前已经在旧 M0 的 Easy/Hard screening 中比较过：

```text
固定末帧读取（fixed-last）
vs.
最后有效状态读取（last-valid）
```

结果是 Hard 场景出现局部正向信号，但 Easy 场景回归；收益没有集中在
`valid_count=1` 或末端缺失样本。因此该实验已经否定了“只读取最后有效状态即可解决缺失读出问题”的简单方案，`last-valid` 不作为后续主方法组件。

该结论不能反过来证明固定末端读出完全没有问题。它只说明：

1. 末端缺失可能造成状态可靠性风险，但读取位置本身未被证明是主要瓶颈；
2. `last-valid` 是一个过于粗糙的离散选择，不能同时处理可靠性与时间新鲜度的冲突；
3. 后续若继续研究读出，只能验证 `last + evidence` 的自适应融合，不能把 `last-valid` 重新包装成新模块。

另外，旧 CMAS/dt 实验中曾观察到 terminal-missing 子组退化，但该实验对应的是“缺失帧仍写入 selective scan 状态”，不是读出位置实验。因此不能把该结果直接归因于固定 `y[:, -1]`。

## 2. 核心研究假设：缺失不是普通输入值

缺失历史的关键问题不是“把一个值填成什么”，而是“这个位置能不能作为证据被其他位置使用”。因此后续编码器应区分三种行为：

1. **空间证据传播**：缺失 actor 可以从有效邻居接收信息，但不应把零占位或不可靠特征作为可靠 key 传给有效 actor。
2. **时间状态传播**：有效观测应正常进入状态；连续缺失期间应降低新输入对状态的干扰，而不是照常吸收占位输入。
3. **最终状态读出**：末端缺失时，最后时间步不能被无条件视为最可靠状态；但此前 `last-valid` 对照已经显示，简单回退到最后有效点也不是稳定答案。因此需要在最新动态和历史证据之间自适应平衡。

因此 OCGT-ENC 的目标数据流为：

```text
原始历史轨迹、有效性 mask、缺失年龄、anchor 几何
        ↓
缺失感知的逐帧关系传播
        ↓
显式相对几何条件注意力
        ↓
有效帧恒等、缺失帧随证据年龄衰减
        ↓
前向/后向状态的可靠性融合
        ↓
证据感知读出
        ↓
原有结构化未来分布 decoder
```

## 3. 拟形成的自有方法：五个相互独立的机制点

### 3.1 缺失感知空间证据传播

当前 GSM 只依据 actor 槽位是否为 padding。后续应增加逐时间步、逐 actor 的观测可用性约束。

对于时刻 `t` 的 query actor `i` 和 source/key actor `j`，建议采用如下语义：

```text
query actor i 可以接收有效 actor j 的消息
缺失 actor j 不作为可靠 key 参与有效 actor i 的消息聚合
缺失 query actor i 仍可从有效邻居和 ghost token 接收消息
padding actor 永不参与消息传播
```

可写成注意力 key 规则：

```text
allowed(i, j, t) = actor_valid(j, t) and not padding(j)
```

ghost token 单独保持可用。这样不是把缺失 query 直接删除，而是允许它通过有效邻居得到上下文，同时避免缺失占位值污染其他 actor。

注意：这里的“方向”指消息从 source/key 到 query 的流向，不应把“缺失 actor → 有效 actor”理解成允许缺失 actor 提供可靠证据。

实现要求：

- 不能只继续使用统一的 `[B, N]` `key_padding_mask`；它无法表达当前时间步的缺失状态。
- 若使用 `nn.MultiheadAttention`，需要构造逐帧的 pairwise attention mask，或改写为显式 QKV logits 计算。
- attention mask 必须同时处理 ghost、padding、当前帧有效性。
- 所有无效 actor 的输出最终仍应乘以 padding mask 置零。

### 3.2 相对几何条件注意力

将 GSM 从“仅凭运动 token 隐式学习关系”改造成显式关系建模。每个时间步、每一对 actor 构造：

```text
relative_geometry(i, j, t) =
[
    dx_ij, dy_ij,
    log(1 + distance_ij),
    dvx_ij, dvy_ij,
    cos(heading_i - heading_j),
    sin(heading_i - heading_j),
    valid_i, valid_j
]
```

其中：

- `dx_ij, dy_ij` 使用当前帧相对位置；
- `dvx_ij, dvy_ij` 使用相邻有效位移或有限差分得到的相对运动；
- heading 使用有效位移方向，角度差用 `sin/cos` 避免 `-π/π` 跳变；
- invalid 或 padding 的几何值可以置零，但必须由 mask 阻止其作为可靠 key；
- Stage 4 主实验只加入几何和当前帧有效性，不提前加入缺失年龄；
- 位置和速度尺度必须与当前数据预处理保持一致，不要在模块内部额外改变坐标系。

关系偏置写为：

```text
b_ij,t = GeometryMLP(relative_geometry(i, j, t))
score_ij,t = q_i,t · k_j,t / sqrt(d) + b_ij,t
```

建议让 `GeometryMLP` 输出每个 attention head 的标量偏置，而不是直接生成高维 value，避免几何分支过度替代内容分支。

该机制的自有表述应是：

> 在缺失观测条件下，以相对几何和观测可用性共同调制行人间消息传播，使空间交互从隐式 token 相关性变成证据条件化的关系建模。

### 3.3 Evidence-Age Gate

不要继续直接使用通用 `Temporal Decay` 的形式。后续应显式区分有效帧与缺失帧，并保证有效帧严格不衰减。

先定义缺失年龄：

```text
age_i,t = 0                         if m_i,t = 1
age_i,t = age_i,t-1 + 1             if m_i,t = 0
```

再定义证据门控：

```text
g_i,t = m_i,t
        + (1 - m_i,t) * exp(-softplus(tau_i) * age_i,t)
```

其中 `m_i,t=1` 表示有效观测。这样：

- 有效帧严格有 `g_i,t=1`；
- 缺失帧随连续缺失长度单调衰减；
- `tau_i` 可以是可学习标量、actor 条件化标量或轻量通道向量；
- 缺失年龄不再只是普通拼接特征，而是直接改变输入证据强度。

建议第一版采用每个 actor/channel 共享的轻量 `tau`，先验证单调衰减是否有用，再考虑更复杂的动态参数。

重要边界：

```text
Evidence-Age Gate 只是在进入 Mamba 前调节输入证据强度，
不等价于修改 selective scan 的离散化步长 Δ，
也不应声称实现了“缺失期间严格 skip-update”。
```

### 3.4 可靠性加权双向 Mamba

当前时序编码器为：

```text
h = h_forward + h_backward
```

后续应让两侧状态根据各自看到的有效证据动态融合：

```text
[alpha_forward, alpha_backward]
    = softmax(ReliabilityNet(
        log(1 + age_forward),
        log(1 + age_backward),
        valid_mask
      ))

h_t = 2 * (
        alpha_forward,t  * h_forward,t
      + alpha_backward,t * h_backward,t
    )
```

乘以 `2` 是为了让初始化为 `0.5/0.5` 时保持与原有“直接相加”大致相同的尺度。

直观解释：

- 前缀缺失时，前向分支证据较弱，后向分支可以利用后续历史观测；
- 末端缺失时，依赖末端附近缺失输入的方向应降低权重；
- 中间缺失但后续恢复观测时，双向分支可以互补；
- 双向 Mamba 不再只是借用结构，而成为观测证据驱动的方向融合机制。

### 3.5 Evidence-Aware Readout

不直接把当前固定读出替换成 `last-valid`。此前旧 M0 screening 已经比较过 `fixed-last` 与 `last-valid`，结果不稳定，且收益没有集中在末端缺失组。因此本阶段研究的是“可靠性加权融合”是否能解决简单离散读出无法同时兼顾可靠性和时间新鲜度的问题。

当前固定读出为：

```python
last = y[:, -1]
```

建议先对所有历史时间步计算证据权重：

```text
r_i,t = ReadoutScore(h_i,t)
        - beta * log(1 + age_i,t)
        + eta * m_i,t

w_i,t = softmax_t(r_i,t)
h_evidence_i = sum_t w_i,t * h_i,t
```

再根据末端证据可靠性融合最后状态和证据汇聚状态：

```text
lambda_i = ReliabilityReadout(
    terminal_valid_i,
    terminal_age_i,
    anchor_lag_i
)

h_final_i = lambda_i * h_last_i
          + (1 - lambda_i) * h_evidence_i
```

其中 `h_last_i` 仍然保留最新时间步信息，`h_evidence_i` 汇聚可靠历史证据。该设计不是简单退回 `last-valid`：

- 有效末端仍可保留最新动态信息；
- 末端缺失时可回退到更可靠的历史状态；
- 缺失期间如果存在可推断的运动变化，soft evidence pooling 仍可能保留其信息；
- 读出过程可以直接用末端缺失、缺失年龄和 anchor lag 解释。

本阶段的研究假设必须写成条件性假设，而不是既定事实：

> 固定末端状态在 terminal-missing 条件下可能受到低可信占位输入影响；如果证据加权融合只在末端缺失子组改善、且不损害全有效子组，才说明它解决了固定读出与最后有效状态之间的可靠性—新鲜度冲突。

## 4. 分阶段实施顺序

所有阶段必须单变量递进。每一阶段先完成代码、行为测试和小规模 sanity run，再决定是否进入下一阶段。

### Stage 0：GAST-PF baseline audit

**目标**：确认当前 `GAST-PF` 是可复现的比较起点，而不是直接在不稳定基线上堆模块。

**实施措施**：

1. 固定当前 `M0` 和 `GAST-PF` 的 decoder、loss、optimizer、数据 split、seed 和 checkpoint 选择规则。
2. 复跑至少一个主场景，并保存 `minADE20`、`minFDE20`、`ADE@1`、`FDE@1`、`MR`。
3. 按 `missing_count`、`valid_count`、`anchor_lag`、`forecast_gap`、`terminal_missing` 和连续缺失长度分组统计。
4. 为 `GAST-PF` 记录参数量、显存、训练时间和输出张量形状。
5. 确认当前 `Temporal Decay`、双向输出和固定末端读出确实对应代码，而不是依赖文档描述。
6. 将历史 `last-valid` screening 作为已知负对照记录，不把它当作新的主实验；后续读出实验必须围绕自适应融合展开。

**验收**：

- `M0` 和 `GAST-PF` 可在相同协议下复现；
- 没有 NaN、空 actor、padding 泄漏；
- 能得到 terminal missing 子组结果；
- 仅当 Stage 0 通过，才继续 Stage 1。

### Stage 1：AnchorGeo

**目标**：最低风险地把已有的 anchor 空间和末端方向信息接入 `GAST-PF`，验证“空间几何缺失”是否是主要瓶颈。

**新增输入**：

```text
x_centers                  [B, N, 2]
cos/sin(last_valid_angle)  [B, N, 2]
anchor_lag_norm            [B, N, 1]
```

`anchor_lag_norm` 可先由 `x_valid_mask` 在模型侧计算：

```text
last_valid_index = max{t | m_i,t = 1}
anchor_lag = (T - 1) - last_valid_index
anchor_lag_norm = anchor_lag / max(T - 1, 1)
```

**具体改造位置**：

- 在 `TrajectoryForecaster.forward` 或 `GASTEncoder` 内增加 `AnchorGeoProjection`；
- 先只在 GAST-PF 的 actor 输出端加入几何投影，不改变 GSM attention；
- 对 padding actor 的几何输入和输出显式置零；
- 保持 decoder 输入维度不变。

**对照**：

```text
GAST-PF
GAST-PF + AnchorGeo
```

**判定**：如果整体不升但 terminal missing 或长缺失子组改善，可保留并进入 Stage 2；如果所有子组均无改善，停止继续堆叠几何模块，先检查坐标尺度和数据泄漏。

### Stage 2：FrameGeo

**目标**：把逐帧位置几何显式送入 GSM，而不是只在最终 actor token 上补位置。

**建议特征**：

```text
relative_position_i,t = x_positions_i,t - x_centers_i
```

新增后的历史输入可先采用：

```text
[x_positions_diff(2), x_velocity_diff(1), valid_mask(1), relative_position(2)]
```

即 `input_dim=6`。第一版不要同时加入复杂速度向量、场景地图或额外社会标签。

**具体改造措施**：

1. 在数据侧确认 `x_positions` 的坐标已经经过当前协议需要的变换。
2. 由每个 actor 的最后有效位置作为 anchor，构造逐帧相对位置。
3. 缺失帧的几何输入置零，但保留 `valid_mask`；不能用未来 target 或插值后的真实位置。
4. 修改 `GASTEncoder` 的 `input_dim` 配置，不要硬编码为 4。
5. 记录全有效子组和不同缺失等级的变化，避免几何输入改善只是因为输入维度增加。

**判定**：只有在相对位置打乱实验能使结果发生预期变化、而 actor permutation 不改变结果时，才说明模型确实在利用几何关系。

### Stage 3：Missing-Key Mask

**目标**：阻止当前缺失 actor 的占位特征作为可靠 source/key 污染有效 actor。

**实现措施**：

1. 修改 `GSMAttnBlock`，让 attention mask 从 `[B, N]` 扩展为逐帧 `[B, T, N]`。
2. ghost token 始终作为可用 key；padding actor 始终屏蔽。
3. 当前帧缺失 actor 不作为 actor key；缺失 query 仍可读取有效 actor 和 ghost。
4. 如继续使用 `nn.MultiheadAttention`，构造 `[B*T*num_heads, N+1, N+1]` 的 logits mask；否则实现显式 QKV attention。
5. 对全缺失邻居帧设置安全路径：至少保留 ghost token，不能产生全 `-inf` 的 attention 行。

**必须测试**：

- 改变缺失 actor 的占位值，valid actor 输出应近似不变；
- 改变 padding actor 的值，valid actor 输出必须不变；
- actor 槽位随机置换，集合输出应按置换对应；
- 全有效输入与当前 baseline 的 mask 路径不能出现意外屏蔽。

**判定**：若行为测试不通过，不进行 Stage 4；优先修正 mask 语义和 attention 数值稳定性。

### Stage 4：Relative Geometry Bias

**目标**：使关系建模显式依赖 focal–neighbor 的相对空间和相对运动，而不是只依赖 token 内容。

**实现措施**：

1. 在 `GSMAttnBlock` 中根据逐帧位置和位移构造 `[B, T, N, N, F_rel]`。
2. 用 `GeometryMLP(F_rel -> num_heads)` 生成每个 head 的关系 bias。
3. 将 bias 加到 attention logits，再叠加 Stage 3 的缺失/padding mask。
4. 几何 bias 只调节 attention 权重，不直接替代 value 分支。
5. 对距离、相对位移做与当前数据一致的尺度归一化，并记录归一化方式。

**负对照**：

- 随机打乱邻居相对几何，但保持 token 和 mask 不变；
- 交换 actor 槽位但同步交换几何；
- 只保留距离、去掉方向；
- 只保留方向、去掉距离。

**判定**：若随机几何与真实几何结果无差别，不能宣称关系模块有效；若 actor permutation 失败，停止并修复集合语义。

### Stage 5：Evidence-Age Gate

**目标**：将当前通用 Temporal Decay 替换为“有效帧恒等、缺失帧按年龄衰减”的任务特定门控。

**实现措施**：

1. 新增独立的 `missing_age` 计算函数，不复用当前“观测点从 1 起算”的 delta 作为严格语义。
2. 实现 `EvidenceAgeGate`，输入 `[B, N, T]` 的 mask 和 age，输出 `[B, N, T, C]` 的 gate。
3. 先采用共享 channel 的可学习 `tau`，确保结构轻量。
4. 在进入前向和后向 Mamba 前分别按对应方向的 age 施加 gate。
5. 保留旧 `Temporal Decay` 作为实验对照，不要在同一版本同时存在两个衰减机制。

**必须测试**：

- 全有效 mask 时 `gate` 逐元素严格等于 1；
- 单个缺失后 age 增大时 gate 单调不增；
- mask 全 0 的 actor 不产生 NaN；
- padding actor 输出仍为零；
- 不使用 future target 计算 age。

**边界**：该阶段只验证输入证据衰减，不把它表述成改变 Mamba 的 `Δ` 或严格 skip-update。

### Stage 6：Direction Reliability Fusion

**目标**：让双向 Mamba 根据前、后向证据可靠性自适应融合。

**实现措施**：

1. 修改 `TemporalEncoder._run` 或其调用接口，使其返回 `y_forw`、`y_back`，不要立即相加。
2. 将后向输出翻转回原时间顺序。
3. 为每个时间步构造 `age_forward`、`age_backward`、validity 和可选的局部有效比例。
4. 用轻量 `ReliabilityNet` 输出两个方向的 logits。
5. 对方向 logits 做 softmax，并用尺度保持式融合：

```text
y = 2 * (alpha_forw * y_forw + alpha_back * y_back)
```

6. 记录 terminal missing 时两个方向的平均权重，作为可解释性诊断。

**判定**：如果权重基本恒定为 0.5 且没有任何缺失等级差异，可暂不保留该模块；如果权重出现极端塌缩，也应先做温度或正则约束，而不是直接接受结果。

### Stage 7：Evidence-Aware Readout

**目标**：在不重复采用已判负的 `last-valid` 路线前提下，检验固定 `y[:, -1]` 是否在 terminal-missing 条件下存在可通过证据加权融合缓解的可靠性问题。

**实现措施**：

1. 保留完整 `[B, N, T, C]` 时序输出到读出层。
2. 用轻量 `ReadoutScore` 为每个时间步产生标量分数。
3. 以 age penalty 和 valid bonus 调整分数，再沿时间维 softmax。
4. 得到 `h_evidence` 后，与 `h_last` 进行可靠性融合。
5. 对 padding actor 先做 mask，再计算读出；避免 padding 时间步进入 softmax。
6. 额外记录每个 actor 的 readout entropy、最大权重时间点和 terminal weight。
7. 将历史 `last-valid` 结果作为负对照：它可以出现在对照表中，但不得作为需要继续调参或组合的独立主线。

**对照**：

```text
fixed-last
last-valid
evidence-only
last + evidence-aware gate
```

其中 `last-valid` 只承担历史负对照作用，不要求重复旧 M0 训练；若因当前 GAST-PF 代码路径不同而重跑，必须标记为诊断实验，不能据此重新宣称该路线有效。不能只比较最终指标，必须报告：

- `terminal_missing=0` 与 `terminal_missing=1/≥2` 子组；
- `anchor_lag` 和连续末端缺失长度曲线；
- 全有效组是否保持不退化；
- 只改变末端缺失占位值时的预测稳定性。

只有在 `last + evidence-aware gate` 相比 `fixed-last` 在末端缺失组稳定改善、相比 `last-valid` 进一步解决时间新鲜度损失，并且全有效组不退化时，才可保留该机制。

### Stage 8：Full OCGT-ENC

**目标**：只组合已经单独通过验收的机制：

```text
FrameGeo
+ Missing-Key Mask
+ Relative Geometry Bias
+ Evidence-Age Gate
+ Direction Reliability Fusion
+ Evidence-Aware Readout
```

组合时保持 decoder、loss、optimizer、数据协议和评测脚本不变。若完整组合反而下降，回退到最近一个通过单变量验收的阶段，不继续增加新模块。

## 5. 统一实验纪律

### 5.1 不变项

每个阶段必须固定：

- `FutureDistributionDecoder`；
- loss 和多模态采样方式；
- TrajGap-Bench Mixed-train/val/test 协议；
- batch size、学习率、weight decay、epoch、warmup；
- fold、seed 和 checkpoint 选择规则；
- 数据归一化、坐标变换和未来 target；
- M0、GAST-PF 的报告指标口径。

### 5.2 必报指标

所有阶段至少报告：

```text
minADE20
minFDE20
ADE@1
FDE@1
MR
```

同时按以下字段做诊断：

```text
missing_count
valid_count
anchor_lag
forecast_gap
terminal_missing
连续缺失长度
scene macro / micro aggregate
```

建议额外记录：

- 参数量、显存峰值和训练时间；
- 完整历史 `m=0` 子组；
- 末端缺失子组；
- 中间缺失后恢复观测子组；
- 高缺失等级子组；
- 预测轨迹的速度、加速度、曲率和转向变化。

### 5.3 必做行为测试

1. **缺失占位不敏感**：只改变缺失 actor 的占位位置或速度值，valid actor 输出不应产生不合理变化。
2. **padding 隔离**：只改变 padding actor 的输入，所有有效 actor 输出保持不变。
3. **几何有效性**：打乱真实 relative geometry 后，模型输出应发生可解释变化。
4. **全有效恒等**：Evidence-Age Gate 在全有效输入上严格为 1。
5. **集合不变性**：同步置换 actor 输入、mask 和几何后，输出按同样置换变化。
6. **末端缺失不泄漏**：读出和所有几何量不得使用 future target 或 future validity。
7. **缺失年龄单调性**：在其他输入不变时，连续缺失长度增加不应使 evidence gate 增大。
8. **安全 attention**：任何合法输入都不能产生全 `-inf` logits、NaN 或空有效 key 集合。

### 5.4 归因规则

- 单个阶段在主指标上提升，同时不损害 `m=0` 和高缺失子组，才可保留。
- 只有改善内部 gate、attention 或权重可视化而不改善未来轨迹指标，不能作为成功。
- 不能把历史 `last-valid` 的局部正向结果解释为固定末端读出问题已经被证明；它只说明简单替换不是稳定解决方案。
- 只有单一场景提升，不足以支持方法级结论；至少需要多数主场景方向一致。
- 若模块增加参数但没有显著收益，应保留为失败记录，不继续叠加。
- 任何收益必须与 M0/GAST-PF 配对重训比较，不能用不同代码状态的结果直接做因果归因。

## 6. Go / No-Go 决策

### Go 条件

满足以下大部分条件，才进入下一阶段或形成完整方法：

- 相比对应基线，主指标有稳定改善或高缺失子组有明确改善；
- terminal missing 和连续缺失场景的收益符合机制预期；
- `m=0` 完整历史子组没有不可接受的退化；
- 行为测试全部通过；
- 多数场景方向一致，而不是单一场景偶然提升；
- 能明确说明新增模块引入了什么不同于已有 mask 的证据传播规则。

### No-Go 信号

出现以下情况时，应停止堆叠并记录失败：

- 模块只是再次拼接 `valid rate`、`missing count` 或 mask summary，没有改变传播或读出机制；
- simple zero/forward fill 已解释全部收益；
- 全有效输入明显退化；
- attention mask 破坏 actor permutation 或 padding 隔离；
- readout 只改善内部权重可视化，不改善 terminal missing 子组；
- 双向可靠性权重塌缩到单一方向且无法解释；
- 几何模块对随机几何打乱不敏感；
- 结果只在一个数据场景或一个 seed 上提升；
- 完整组合比最近一个单模块版本更差，且无法通过消融定位冲突来源。

若出现 No-Go，不应继续增加模块数量，而应收缩主张，转向“缺失历史下的系统评估与失败边界”，或只保留通过验证的单个机制点。

## 7. 后续论文叙事建议

最终论文不应写成：

> 将外部方法的 GSM、Temporal Decay 和双向 Mamba 直接拼接到现有预测框架中。

更合适的叙事是：

> 针对缺失历史轨迹预测中“无效观测可能被错误传播、不同时间方向证据可靠性不对称、末端缺失导致固定读出失真”三个问题，提出观测证据条件化的几何时序编码器。该编码器分别在关系传播、时间状态调制、双向状态融合和最终读出阶段使用观测有效性与缺失年龄，使缺失结构成为信息流控制变量，而不仅是输入特征。

创新边界应明确写为：

1. `GSM`、`Temporal Decay`、双向 `Mamba` 是借用的基础机制；
2. 本文的任务特定改造是缺失 key 隔离、相对几何关系偏置、有效帧恒等的 evidence-age gate、方向可靠性融合和证据感知读出；
3. 贡献是否成立取决于消融和行为测试，而不是模块数量或模型名称；
4. 若后续实验不能证明这些机制在缺失历史任务上有效，不应强行包装为创新。

---

## 8. 给后续代码 agent 的最小执行指令

1. 只从 `Stage 0` 开始，不直接实现 `Stage 8`。
2. 每个 stage 使用独立配置名和独立输出目录，禁止覆盖 M0、GAST-PF 原始结果。
3. 每次只改一个机制点；修改前后保存参数量和配置快照。
4. 先写行为测试，再启动训练；测试失败时停止，不通过训练结果掩盖实现错误。
5. 保持 decoder、loss、数据协议、评估脚本不变。
6. 每个阶段完成后提交：代码路径、配置路径、测试命令、训练命令、结果表、失败分析和是否进入下一阶段。
7. 不恢复 `CondDeltaMamba`、ODMR/M0、M1、重建辅助分支或其他已否定路线。

## 9. 当前结论

当前 `GAST-PF` 可以作为结构替换基线，但尚不能作为最终创新方法。最值得优先验证的不是继续叠加更多 Mamba 层，而是：

```text
先补充显式几何
→ 再限制缺失证据传播
→ 再保证有效帧恒等、缺失帧按年龄衰减
→ 再做双向可靠性融合
→ 最后检验并修正末端缺失下的读出
```

其中读出阶段不再重复“固定末帧 vs 最后有效帧”的简单替换，而是把已有 `last-valid` 负结果作为边界，重点验证证据加权融合是否能够同时保留最新动态和可靠历史信息。这条路线把借用模块转换为面向缺失历史轨迹任务的结构化信息流设计，同时保留了清晰的单变量实验路径和失败退出机制。
