# 解码器优化文献调研

_2026-10-21 · 对象：GAST-PF 的 `FutureDistributionDecoder`（4,099,192 参数，占总参数 78.6%）_

## TL;DR

当前解码器有三个**已被文献明确诊断过**的结构性问题：

1. **静态 mode query + 硬 WTA 训练** → 初始化敏感与模式塌缩（aWTA, ICRA 2025 直接针对此问题）；
2. **模式置信度用硬标签 CE 训练** → `pi` 校准不良，直接拖累 ADE@1/FDE@1（ModeSeq, CVPR 2025 的原话是 "uncalibrated mode confidence"）；
3. **两套并行解码头**（mode query 与 hybrid coupling）各自完整训练，但测试只用后者 → 约 1.28M 参数（总参数的 24.5%）可能是冗余容量。

**性价比最高的三个方向**（按改动量从小到大）：

| 优先级 | 方案 | 改动 | 预期收益 | 风险 |
| --- | --- | --- | --- | --- |
| P1 | 退火 WTA（aWTA） | 只改 loss | minFDE20 覆盖能力 | 低 |
| P2 | 模式置信度软标签校准 | 只改 CE 目标 | ADE@1 / FDE@1 | 低 |
| P3 | 双头消融（去 mode head） | 删模块 | 训练加速 + 可能提精度 | 中 |

**不建议**在 ETH/UCY 上直接上 anchor 库（MultiPath/DenseTNT/LaPred 那一路）——那是为车辆的多车道分支设计的，行人目的地分布窄，anchor 的边际收益存疑，且引入额外超参。

## 1. 当前解码器的结构事实

### 1.1 数据流

```
actor_feat [B,N,128]
   ↓
Ⅰ State Consistency Module   state query × actor 交叉注意力 + 双向 Mamba → dense_predict
Ⅱ Mode Localization Module   20 个静态 query + 自注意力 + 交叉注意力 → y_hat / pi / scal
Ⅲ Hybrid Coupling Module     mode × state 耦合自注意力 + 交叉注意力 → new_y_hat / new_pi
```

测试只用 `new_y_hat` / `new_pi`。

### 1.2 关键实现（含代码位置）

| 组件 | 实现 | 位置 |
| --- | --- | --- |
| mode query | `nn.Embedding(20, 128)`，与 `encoding[:,0]`（focal token）相加 | `structured_future_decoder.py:140, 215` |
| 轨迹头 | `Linear(128→256)→GELU→Linear(256→24)` → `[B,20,12,2]`，**直接输出位移** | `:46-76` |
| 尺度头 | 同结构，`ELU+1+1e-4` → 每步每轴独立 Laplace scale | `:64-67` |
| 置信度 | `Linear(128→64)→GELU→Linear(64→1)` → softmax | `:60-63` |
| 回归损失 | **硬 WTA**：取误差最小的 mode 做 SmoothL1 | `forecasting_module.py:109` |
| 分类损失 | `CE(pi, argmin_mode)`，`label_smoothing=0.2` | `:110` |
| 似然损失 | 全 K 模式的 Laplace NLL（混合似然） | `:139, 144` |

## 2. 文献分类

### A. 训练目标：WTA / Multiple Choice Learning

**Annealed Winner-Takes-All (aWTA)** — ICRA 2025，arXiv:2409.11172 [1]

摘要原文的关键诊断："these methods face **initialization sensitivity and training instabilities**. Additionally, to compensate for limited performance, some approaches rely on training with a large set of hypotheses, requiring a post-selection step during inference."

方法：把硬 WTA 换成**退火式软分配**——训练早期用较软的分配（多个近优模式共同获得梯度），随训练推进逐步退火到硬 WTA。作者声明该改动"can be easily incorporated into any trajectory prediction model normally trained using WTA and yields significant improvements"，且"using only a minimal set of hypotheses"，消除事后筛选。

**与我们架构的对应**：我们正是硬 WTA（`y_hat_best` = argmin）+ 20 个模式。初始化敏感问题在训练日志里可能已有痕迹（不同 seed 的 best epoch 从 49 到 97 不等）。

**ModeSeq + EMTA** — CVPR 2025，arXiv:2411.11911 [2]

诊断："existing works predominantly adopt the winner-take-all training strategy... yet still suffer from **limited trajectory diversity and uncalibrated mode confidence**."

方法：把模式当作**序列**逐步解码（mode 之间显式建模相关性），并配 Early-Match-Take-All（EMTA）训练。

**对应**：我们的 20 个 mode 是一次性并行解码的，彼此只通过 `mode_self_attention_layers` 交互。ModeSeq 指出一次性并行解码难以捕捉模式间相关性。但这是较大的结构改动。

### B. 模式条件化：anchor / 目标点

**MultiPath** — CoRL 2020，arXiv:1910.05449 [3]

用固定的 anchor 轨迹集合，每个 anchor 预测偏移量 + 概率。这是"静态 query"的经典替代。

**DenseTNT** — ICCV 2021，arXiv:2108.09640 [4]

摘要原文点出前作的局限："these methods usually involve goal predictions based on **sparse pre-defined anchors and heuristic goal selection** algorithms." 改为密集目标点候选 + 端到端直接输出轨迹集合。

**LaPred** — CVPR 2021，arXiv:2104.00249 [5]

用车道实例作为候选，**自监督学习"目标 agent 最可能跟随哪个车道"**，再用该注意力权重融合各候选特征。这是"候选 + 重排序"的范式。

**为什么这条路线对我们优先级低**：三者都建立在**车辆/结构化道路**的多分支语义上（车道、可行驶区域）。行人在 ETH/UCY 上的目的地分布远比车辆窄，且我们没有地图。anchor 库需要先做位移聚类，引入"聚类数/聚类方式"两个新超参，在单种子 screening 下很难干净归因。

### C. 不确定性建模

**DD-MDN** — ICRA 2026，arXiv:2602.11214 [6]

扩散 + 双混合密度网络 + 不确定性自校准。属于"生成式 + 概率头"路线。

**对应**：我们用的是每步每轴独立的 Laplace（对角、无时间相关性）。更丰富的似然（完整协方差 / Student-t / 混合）会改善 NLL，但**对 minADE/minFDE/ADE@1/FDE@1 四项指标没有直接作用**——除非同时改变采样与重排序。优先级最低。

### D. 综述定位

**Recent Advances in Multi-Agent Human Trajectory Prediction: A Comprehensive Review** — arXiv:2506.14831 [7]

2026 年的多智能体行人轨迹预测综述，可用于确认当前 ETH/UCY 上的主流范式与解码器设计趋势。

## 3. 弱点 → 文献 → 预期影响

| 我们的弱点 | 文献依据 | 直接影响的指标 | 改动量 |
| --- | --- | --- | --- |
| 硬 WTA + 20 静态 query，初始化敏感 | [1] aWTA | minFDE20（覆盖能力） | 仅 loss |
| `pi` 用硬 argmin 的 CE 训练，置信度未校准 | [2] ModeSeq | ADE@1 / FDE@1（排序质量） | 仅 loss |
| 静态 query 与输入无关 | [3][4][5] | 多模态质量 | 中（需 anchor 设计） |
| 模式并行独立解码，无序列依赖 | [2] ModeSeq | 模式相关性 | 大 |
| 双头并行、测试只用其一 | 无直接文献；属工程冗余 | 训练效率 / 容量 | 中（删除） |
| 对角 Laplace，无时间相关 | [6] DD-MDN | NLL（非主指标） | 大 |

## 4. 推荐方案（按性价比排序）

### P1 · 退火 WTA（只改 loss）

把 `agent_reg_loss` 的硬 argmin 换成温度退火：

```
τ 从 τ0 线性/余弦退火到 0
权重 w_k ∝ exp(-FDE_k / τ)，w 归一化
reg_loss = Σ_k w_k · SmoothL1(y_hat_k, y)
cls_target = w（软标签）而非 one-hot
```

- **依据**：[1] 明确说可插入任何 WTA 模型且收益显著；
- **改动面**：`forecasting_module.py` 的两处 loss + 一个 schedule；
- **验收**：minFDE20 宏平均改善 ≥1%，且 `minADE20` 不退化超过 0.5%；不同 seed 的 best epoch 离散度下降；
- **风险**：退火曲线（τ0、退火速度）是新超参，需要小规模扫。

### P2 · 模式置信度校准（只改 CE 目标）

现在 `CE(pi, argmin)` + label_smoothing=0.2。改为按模式质量构造软目标：

```
q_k ∝ exp(-FDE_k / τ_cls)      # 质量越好的模式目标概率越高
cls_loss = CE(pi, q)
```

- **依据**：[2] 明确指出 WTA 训练导致 "uncalibrated mode confidence"，而我们的 ADE@1/FDE@1 完全依赖 `pi` 的排序；
- **改动面**：一行 loss；
- **验收**：ADE@1/FDE@1 宏平均改善 ≥2%（这两项我们现在相对 MoFlow 已领先 10–11%，但相对内部基线只有 1–2%）；
- **风险**：极低。可与 P1 组合，但**必须分开做单变量**。

### P3 · 双头消融

删掉 Mode 分支（`mode_self_attention_layers` + `mode_context_layers` + `mode_trajectory_head`），只保留 Coupled 分支输出。

- **依据**：工程冗余，无直接文献。但 24.5% 的参数只做辅助监督，值得验证；
- **改动面**：删模块 + 改 forward 与 loss（去掉 `agent_reg_loss`/`agent_cls_loss`/`laplace_loss`）；
- **验收**：四项指标不退化（允许 ≤0.3%），训练时间下降 ≥15%；
- **风险**：中。如果辅助监督实际在起正则作用，删掉会退化——那本身就是有价值的负结果。

### 不做（至少现在不做）

- **anchor 库**（MultiPath/DenseTNT/LaPred）：行人 + 无地图 + 单种子，归因困难；
- **ModeSeq 式序列解码**：结构改动大，与当前"单变量、可归因"的实验纪律冲突；
- **扩散/flow 解码器**：MoFlow 本身就是这条路线的 SOTA，我们换掉它等于换赛道，不是优化。

## 5. 撞车风险评估

| 方案 | 撞车风险 | 说明 |
| --- | --- | --- |
| P1 aWTA | **高** | [1] 已把该 loss 做成通用插件并在多个 SOTA 模型上验证。**只能作为 borrowed control，不能主张创新** |
| P2 软标签置信度 | 中 | 软目标/知识蒸馏式的分类监督在检测领域常见；行人轨迹预测里未见明确对应工作，但机制朴素，**不宜作为主贡献** |
| P3 双头消融 | 低 | 属消融实验，不构成主张 |

**定位建议**：P1/P2 都应写成"对现有解码器的工程改进 + 消融证据"，而不是新方法。真正可主张的部分仍然在**观测证据条件化**那条线上（Stage 0–2 的教训说明那里也还没打通）。

## 6. 实验设计建议

三项都是**单变量、可快速验证**的，不需要五场景全跑就能初筛：

| 阶段 | 范围 | 判据 |
| --- | --- | --- |
| 冒烟 | ETH-M，20 epoch | loss 正常下降、无 NaN、`pi` 不塌缩（熵不趋 0） |
| 初筛 | ETH-M + ZARA1-M，100 epoch | 相对 GAST-PF 基线，目标指标改善 ≥1% 且其他指标不退化 >0.5% |
| 铺开 | 五场景 | 宏平均 + 样本加权双口径 |

**必须先建立同口径基线**：现在的 `GAST-PF` 参考数字是旧 monitor 口径（`val_minFDE20`），而新实验用 `val_new_minFDE20`。P1/P2 的任何结论都需要先补一条新口径的 GAST-PF 五场景基线，否则又回到 Stage 1/2 那种"非配对对照"的困境。
