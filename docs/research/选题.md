## 0. 标题、摘要与关键词

**中文标题**：观测证据条件化的缺失历史行人轨迹预测：直接预测协议与统一证据路由

**English title**：Evidence-Conditioned Spatiotemporal Routing for Pedestrian Trajectory Prediction from Missing Histories

**备选标题**
- 缺失历史下的行人多模态轨迹预测：不插补的直接预测与证据可靠性路由
- When Missing Frames Cannot Be Trusted: Evidence-Conditioned Routing for Pedestrian Trajectory Prediction

**关键词**：pedestrian trajectory prediction；missing observations；direct missing-history forecasting；evidence-conditioned routing；multimodal forecasting；benchmark protocol

### 摘要（中文草稿）

行人轨迹预测通常假定历史轨迹完整、连续且等间隔，而检测与跟踪系统在遮挡、漏检、视野离开和跟踪中断时给出的历史轨迹往往带有时间缺口。现有两条主流路线都不足以处理这一设定：先插补再预测的串行管线把插补误差与插补不确定性一并送入预测器；只把掩码拼接进输入的缺失感知模型则把缺失帧当作普通输入值，使无效观测仍可向邻居和后续时刻传播"证据"。本文提出观测证据条件化时空路由（Evidence-Conditioned Spatiotemporal Routing，ECSR）：把观测有效性与缺失年龄统一为一个共享证据状态，并用同一状态控制空间消息的源资格、时序输入强度、双向路径融合和最终历史读出，从而保证"缺失观测可以消费上下文，但不能伪装成可靠观测向外制造证据"，且在全有效输入时严格退化为原编码器。配套地，本文在 TrajImpute 官方缺失 release 上定义直接缺失历史预测协议 TrajGap-Bench（Mixed 训练/验证/测试、不做任何插补、K=20、以 minADE20/minFDE20 为主指标），在 ETH/UCY 五个场景上与内部基线、经典社会池化基线和流匹配强基线统一比较，并按缺失帧数、末端缺失和邻居可用性分层报告退化行为。当前已完成直接预测基准与骨干替换的验证，ECSR 的机制收益仍处于待验证状态，本文同时给出其可证伪的验证设计。

### Abstract (draft)

Pedestrian trajectory predictors usually assume a complete, continuous and uniformly sampled history, whereas detection-and-tracking pipelines produce histories with temporal gaps caused by occlusion, missed detections, field-of-view limits and track fragmentation. Neither dominant remedy is satisfactory: impute-then-predict pipelines propagate both imputation error and the (often mis-calibrated) uncertainty of single imputation into the predictor, while mask-concatenation models treat missing steps as ordinary input values and therefore let invalid observations act as evidence for neighbours and for later time steps. We present Evidence-Conditioned Spatiotemporal Routing (ECSR), which represents observation validity and observation age as one shared evidence state and uses that single state to gate (i) which actors may act as spatial message sources at each frame, (ii) how strongly each step enters the temporal state update, (iii) how forward and backward paths are fused, and (iv) how the history is finally read out. The design satisfies two testable properties: missing observations may consume context but may not emit evidence, and fully observed inputs reduce exactly to the base encoder. We further define TrajGap-Bench, a direct missing-history protocol built on the official TrajImpute release (Mixed train/val/test, no imputation, K=20, minADE20/minFDE20 as primary metrics), and report results on the five ETH/UCY scenes against an internal baseline, a classic social-pooling baseline and a flow-matching baseline, together with stratified degradation analysis over missing counts, terminal missingness and neighbour availability.

## 1. 引言

### 1.1 问题

行人轨迹预测把检测与跟踪系统输出的历史轨迹作为输入，输出未来若干秒的多条候选轨迹及其概率。主流基准（ETH/UCY、SDD 及其派生协议）在构造样本时要求历史窗口完整、连续、等间隔，这使模型可以直接由位置差分获得速度、方向与转向趋势。真实系统不满足这一前提：遮挡与视野离开造成短时不可见，漏检与帧丢失造成离散时刻缺失，跟踪中断与重新关联造成片段断裂，定位质量下降造成坐标不可信。第一视角（egocentric / first-person view）部署使这些缺陷更集中：视野边界与遮挡天然把缺失推到观测窗口末端。

历史一旦出现缺口，损失不只是若干坐标：可用于区分未来分支的行为证据被抹掉，可用于初始化未来演化的运动锚点变弱，最近一次有效观测与预测起点之间还可能存在时间脱节。因此缺失历史不是"输入维度少了几行"，而是改变了模型可用的历史证据及其时间组织方式。

### 1.2 两条现有路线的问题

**（一）先插补、再预测（impute-then-predict）。** 该路线先用插补器恢复一条"完整"历史，再交给预测器。它的问题在统计上是已知的：单值插补忽略缺失值本身的不确定性，把估计值当作已知值使用，导致下游估计有偏、推断无效[15]；系统性实证也显示插补器的重建精度与其不确定性校准经常不一致，高精度重建并不等于可靠的不确定性[16]。在行人轨迹上，官方缺失基准显示插补后输入使各类预测模型整体退化，缺失越重退化越明显，并据此把"直接处理缺失坐标的模型"列为开放问题[5]；插补与预测联合建模的工作也指出自回归式插补容易累积复合误差[3][4]。第一视角场景的实测进一步给出量级：同一模型从鸟瞰输入切到第一视角输入，ADE/FDE 由 0.44/0.89 m 恶化到 1.51/2.08 m，且缺失并非随机缺失而是由遮挡与视野机制决定[9]。此外，估计理论给出机制性解释：观测到达率低于临界值时，状态估计的误差协方差不再有界[17]，这对应"连续缺 4–7 帧"并非线性变差，而可能接近质变。

**（二）只把掩码拼进输入的缺失感知模型。** 该路线把有效性掩码作为额外输入通道，由网络自行学习如何使用。它避开了插补误差，但留下一个结构性漏洞：掩码只是一个特征，模型没有关于"哪条信息可以向外传播"的约束。缺失帧的占位值仍会作为空间消息的 key 参与邻居聚合，仍会写入时序状态，仍会在双向融合与末端读出中被当作最新状态。结果是缺失观测在表示层被"洗白"，无效信息以合法通道扩散到有效 actor 与后续时刻。第一视角与遮挡推理方向的文献从另一侧印证了这一点：已有工作明确指出多数方法"只预测可见对象、不维护被遮挡对象的不确定性"[28]，以及历史去噪与未来预测需要共享隐表示而非串行两段[10]。

### 1.3 本文思路

本文不恢复一条唯一的历史轨迹，而是在两个层面处理该问题：

1. **任务与协议层**：把"完整历史 → 未来"改写为"缺失历史观测 → 未来"的条件预测问题，输入为带缺口的观测、有效性掩码、观测间隔与场景交互上下文，输出完整未来轨迹的多模态分布；评测在**不做任何插补**的直接协议下进行，避免把插补质量与预测质量混为一谈。
2. **方法层**：引入观测证据条件化时空路由（ECSR），把观测有效性与缺失年龄统一为一个共享证据状态，并用同一状态在四个信息流落点施加控制——空间消息源资格、时序输入强度、双向路径融合、历史读出。其核心不变量是"缺失观测可以消费上下文，但不能伪装成可靠观测向外制造证据"，以及"全有效输入严格退化为基础编码器"。

## 2. 相关工作

### 2.1 缺失历史下的轨迹预测

按对缺失的处理范式可分为四类。**联合插补–预测**：GC-VRNN 用多空间图网络编码不完整观测，并把缺失模式作为条件，同时输出插补与预测[3]；MS-TIP 用对角掩码自注意力做插补、多尺度超图做交互、并以中间控制点细化终点[4][6]。**两步插补–预测**：TrajImpute 建立缺失数据基准，系统评测插补器与预测器组合，并给出"预测模型难以有效使用插补数据"的结论[5]。**直接预测**：STGN-IT 以时空图加观测状态编码直接吃不完整轨迹[7]；RMP-YOLO 则反向主张"先重建完整历史再预测"[8]。**噪声而非缺失**：RealTraj 类工作把检测噪声直接作为输入，处理的是坐标扰动而非时间缺口。第一视角方向另有专门处理：T2FPV 把鸟瞰数据渲染为第一视角并用端到端修正模块衔接插补与预测[9]；EgoTraj-Bench 用真实第一视角噪声历史配对干净鸟瞰未来，并以双流流匹配同时去噪历史与预测未来[10]；OSQF-Net 用记忆库恢复"伪完整"运动特征再做时空融合[11]。

### 2.2 插补误差与"插补不等于预测"

统计文献早已给出结论：以重建误差（如 RMSE）最优为准则选出的单值插补，恰好是忽略缺失值固有不确定性的那一种，因而会产生有偏估计与无效推断；重建相似度本身不能区分有效与无效的插补方法[15]。近期的插补不确定性实证研究进一步显示，重建精度与不确定性校准经常不一致，需要在下游管线中按不确定性感知标准选择插补器[16]。这两条结论共同支持本文的立场：在缺失历史预测中，"把历史补好"与"把未来预测好"不是同一个目标，评测必须绕开插补环节。

### 2.3 缺失感知的时序骨干

时序预测领域已有成熟的免插补范式：把缺失模式作为结构偏置逐层注入[19]、用表征流与掩码流双流建模[20]、在不规则序列上做可变换的 patch 化[26]、用梯度重加权直接从不完整输入训练[25]、以及用条件正规化流直接从缺失不规则序列预测[24]。本文的骨干直接借鉴轨迹领域的 UniTraj / Sports-Traj：逐帧空间注意力加 ghost token、按缺失游程的指数衰减（BTS）、双向状态空间扫描[21]。**这些机制均为借用，本文不主张其原创性**；ECSR 的差异化主张只在"同一证据状态控制信息流资格与强度"这一层。

### 2.4 观测长度、末端观测与不确定性

观测越短、越不完整，预测越难：极短观测（两帧）设定下，两帧都被用于估计速度，说明最近观测承担速度与航向锚点[12]；检测与跟踪的碎片化误差会累积并显著损害预测[13]；观测长度偏移被视为分布层面而非坐标层面的问题[14]。不确定性侧，网络在分布外输入上容易过度自信[18]，感知噪声会向上游污染预测并需要同时建模感知不确定性与预测不确定性[27]；遮挡对象应维护存在性与状态的后验，而不是只预测可见对象[28]。Kalman 滤波的间歇观测理论则给出"观测到达率低于临界值 → 误差协方差无界"的机制解释[17]。据本文检索，尚无工作把"缺失模式（连续帧数、缺失位置、尤其观测窗末端缺失）"与"未来分布的可靠性（校准、覆盖率、spread）退化"联系起来做定量分析，这一空白正是 C4 的落点。

## 3. 问题定义

记目标行人（focal）的完整历史为 $X_{1:T_h}\in\mathbb{R}^{T_h\times 2}$，未来为 $Y_{1:T_f}\in\mathbb{R}^{T_f\times 2}$，历史有效性掩码为 $M_{1:T_h}\in\{0,1\}^{T_h}$。输入观测为

$$X^{obs}_t = M_t\odot X_t ,$$

即缺失时刻的位置不提供数值（在实现中为 NaN，经掩码后不进入有效计算）。由观测过程导出的条件量为

| 记号 | 含义 |
|---|---|
| $M_t$ | 第 $t$ 时刻是否存在有效观测 |
| $\Delta_t$ | 距最近一次有效观测的时间间隔（缺失年龄） |
| $r_{i,t}$ | 由 $M$ 与 $\Delta$ 得到的连续证据强度（见 §4.3） |
| $C$ | 场景交互上下文（邻居观测、相对几何、场景归一化参照系） |

任务目标是建模

$$p_\theta\big(Y_{1:T_f}\mid X^{obs}_{1:T_h}, M_{1:T_h}, \Delta_{1:T_h}, C\big),$$

**训练与评测中未来轨迹始终完整**，缺失只发生在输入历史窗口。轨迹插补可以作为对照方法出现，但不是本文的目标，也不构成输入管线的一环。评测按 K 条候选计算 best-of-K 与 top-1 两类指标（§5.3）。

**与插补后预测的口径区别**（论文中必须显式声明）：直接预测的输入是缺失坐标加掩码，输出多模态未来；插补后预测的输入是插补器恢复的单条历史，输出按单轨 ADE/FDE 计。两者不可混入同一数值表，也不可互相折算。

## 4. 方法

### 4.1 总体结构与固定接口

本文的模型由一个**历史编码器**与一个**结构化未来分布解码器**组成。解码器、损失、采样方式与评测脚本在所有对照中保持不变，因此方法层的任何差异都可归因于历史编码器及其信息流控制。这一"固定接口"是全部配对实验成立的前提。

```text
缺失历史 X^obs + 掩码 M + 缺失年龄 Δ + 场景上下文 C
        ↓  历史编码器（本文方法所在）
   H ∈ R^{N×d}    （每个 actor 一个 token）
        ↓  未来分布解码器（固定，不修改）
   K 条候选轨迹 + 模态概率
```

### 4.2 基础编码器（GAST-PF，✅ 已验证）

基础编码器逐层为：

```text
hist_feat = [位移差分(2), 速度变化(1), 有效性掩码(1)]        [B,N,T,4]
   → 逐帧空间注意力 GSM + ghost token（逐时间步在 actor 集合上聚合上下文）
   → 前向/后向缺失游程 δ（距最近有效观测的步数）
   → Temporal Decay:  x' = γ ⊙ x,  γ = exp(-ReLU(MLP(δ)))
   → 前向 Mamba + 后向 Mamba（两套独立参数，反向序列扫描后翻转相加）
   → 固定读取末端状态 y[:, -1]
   → [B,N,128] → 固定解码器
```

参数量 5,213,968（编码器 1,067,136；解码器 4,099,192）。**该编码器的空间注意力、ghost token、缺失游程衰减与双向状态空间扫描均借自 UniTraj / Sports-Traj[21]**，本文只主张"在缺失历史任务上选择并验证该骨干"这一工程与实证贡献（C2），不主张机制原创。

基础编码器暴露的结构性缺口（正是 ECSR 的动机）：

1. 空间注意力的 `key_padding_mask` 只能屏蔽 padding actor，无法表达"当前帧缺失的 actor 不应作为可靠 key"；
2. `Temporal Decay` 在有效帧上也不严格为 1，可能衰减真实观测；
3. 前向与后向输出无条件相加，未按两侧观测证据的可靠程度分配权重；
4. 固定读取 `y[:, -1]`，当末端缺失时该状态并非最新可靠证据；
5. 关系由内容注意力隐式学习，缺少显式的 focal–neighbor 相对几何条件。

### 4.3 观测证据条件化时空路由（ECSR，◐ 待验证）

ECSR 用一个**共享证据状态**贯穿四个信息流落点。它不是四个并列模块，而是一条控制律的四种落点；实验上可以逐点启用以完成归因，但论文只把它作为一个主机制主张。

**共享证据状态。** 对 actor $i$、时刻 $t$，定义连续证据强度

$$r_{i,t}=\begin{cases}1, & M_{i,t}=1\\ \exp(-a_{i,t}/\tau), & M_{i,t}=0\end{cases}\qquad \tau=\mathrm{softplus}(\theta)>0,$$

其中 $a_{i,t}$ 为缺失年龄（连续缺失步数），$\tau$ 为全路由共享的轻量参数。约束：有效帧严格 $r=1$（修正基础编码器在观测点仍衰减的问题）；缺失帧随年龄单调衰减。

**落点 ①：空间消息源资格。** 对 query actor $i$ 与 source actor $j$：

$$\mathrm{allowed}(i,j,t)=M_{j,t}\ \wedge\ \neg\mathrm{padding}(j).$$

只限制 source/key，不删除 query：缺失 actor 仍可从有效邻居与 ghost token 接收上下文，但缺失 actor 不作为可靠 key 向外发送消息。该规则需要逐帧 pairwise attention mask（统一的 $[B,N]$ `key_padding_mask` 无法表达）。

**落点 ②：关系路由（相对几何作为条件）。** 每对 actor 构造相对几何向量

$$g_{ij,t}=[\,dx,dy,\log(1+d),dv_x,dv_y,\cos\Delta\theta,\sin\Delta\theta\,],$$

并以它生成注意力偏置

$$s_{ij,t}=\frac{q_i^\top k_j}{\sqrt{d}}+b_{ij,t},\qquad b_{ij,t}=\mathrm{GeometryMLP}(g_{ij,t}).$$

相对几何只在 query 与 source **都有直接位置观测**时计算；任一方缺失时偏置置为中性值 0，避免把占位坐标当成真实空间关系。`GeometryMLP` 输出每个注意力头的标量偏置，不生成高维 value，以免几何分支替代内容消息。

**落点 ③：状态路由（证据新鲜度门控）。** 进入前向/后向状态空间块之前，用同一 $r$ 缩放输入

$$x'_{i,t}=r_{i,t}\cdot x^{spatial}_{i,t}.$$

边界必须写清：该门控只调节进入状态空间块的证据强度，**不修改 selective scan 的离散化步长 $\Delta$，也不声称实现缺失期间严格 skip-update**。

**落点 ④：路径融合与读出路由。** 双向路径不再无条件相加，而按两侧的缺失负担分配权重：

$$D^{f}_{i,t}=\sum_{s\le t}(1-r_{i,s}),\quad D^{b}_{i,t}=\sum_{s\ge t}(1-r_{i,s}),$$

$$[\alpha_f,\alpha_b]=\mathrm{softmax}([-D^f,-D^b]),\quad h_{i,t}=2\,(\alpha_f h^f_{i,t}+\alpha_b h^b_{i,t}).$$

系数 2 使全有效输入时两侧权重为 0.5 并恢复原来的 $h^f+h^b$。读出同样由 $r$ 条件化：

$$w_{i,t}=\mathrm{softmax}_t\big(\mathrm{ReadoutScore}(h_{i,t})+\beta\log r_{i,t}\big),\quad h^{ev}_i=\sum_t w_{i,t}h_{i,t},$$

$$h^{final}_i=r_{i,T}\,h_{i,T}+(1-r_{i,T})\,h^{ev}_i .$$

即末端有效时保留最新动态，末端缺失时才引入历史证据——这**不是**把读出简单替换为 last-valid（该简单替换已在早期实验中失效，见 §6.4）。

### 4.4 可验证性质与行为测试

ECSR 的可证伪性由三条性质与一组行为测试承担（表内为必测项）：

| 性质 | 陈述 | 测试方式 |
|---|---|---|
| P1 全有效恒等 | 当 $M\equiv 1$ 时，$r\equiv 1$、$\alpha_f=\alpha_b=0.5$，输出与基础编码器逐元素一致 | 同一权重下比较两条前向 |
| P2 证据源不伪造 | 缺失 actor 可接收邻居消息，但不能作为有效 actor 的可靠 key | 篡改缺失 actor 占位值，检查有效 actor 输出是否不变 |
| P3 缺失年龄单调 | 其他输入不变时，连续缺失长度增加不使 $r_{i,t}$ 增大 | 扫描连续缺口长度，记录 $r$ 曲线 |

其余必测项：padding 隔离（只改 padding actor，有效 actor 输出不变）；集合等变（同步置换 actor/掩码/几何，输出按同一置换变化）；几何有效性（打乱真实相对几何后输出应发生可解释变化）；末端不泄漏（读出与几何量不得使用未来 target 或未来有效性）；安全注意力（任何合法输入不产生全 $-\infty$ 或 NaN）；共享状态一致性（四个落点的输入必须来自同一 `missing_age` 与证据状态）。

## 5. TrajGap-Bench：直接缺失历史预测协议

### 5.1 协议定义与身份边界

**TrajGap-Bench 是本文定义的直接缺失历史预测基准协议**，数据层复用 TrajImpute 官方发布的 Easy/Hard release，任务层取消"先插补再预测"，协议层把同一 split 的 Easy/Hard 样本合并为 Mixed。

| 项 | 设定 |
|---|---|
| 数据来源 | TrajImpute 官方 release pkl（5 场景 × Easy/Hard × 3 split = 30 个文件；来源核验与全量审计见 [`docs/audits/trajimpute_release_审计.md`](../audits/trajimpute_release_审计.md)） |
| 历史 / 未来 | 8 帧观测 / 12 帧预测 |
| 缺失强度 | Easy：每轨迹缺失 0–4 帧（均值约 25%）；Hard：恰为 4–7 帧（均值约 68.7%）；每样本至少保留 1 个有效观测 |
| Mixed 组织 | 同一 split 内 Easy + Hard 合并；train/val/test 均为 Mixed，输入为缺失历史 + 掩码 + 观测间隔 + 场景信息，**不经任何插补** |
| 场景 | ETH-M / HOTEL-M / UNIV-M / ZARA1-M / ZARA2-M |
| 测试规模 | 1,629 / 9,477 / 219,006 / 20,277 / 52,497，合计 302,886（所有方法完全一致） |
| 训练配置 | seed 2024，K=20，100 epochs，batch size 64 |
| 选点 | 按最终预测头 `val_new_minFDE20` |
| 主指标 | `minADE20`、`minFDE20`（并列报告，不合成单一分数） |
| 辅助诊断 | `ADE@1`、`FDE@1`（取最高概率模式）；MR 不属于本协议 |

**必须写明的边界**：TrajImpute 只提供缺失数据 release 与其原论文的插补后预测参考（Clean / Easy-impute / Hard-impute）；TrajGap-Bench 的 Mixed 组织、direct 输入形式、checkpoint 选点与主评测口径均属本文协议。**本文结果不得表述为"TrajImpute 官方 direct benchmark"或"官方 direct 结果"**，也不与官方插补后预测数字并排在同一张"官方数值"表中。官方 release 不含原生 direct 评估器，本文评估器为自实现。

### 5.2 与插补后预测的比较口径

```text
直接预测（本文）：缺失历史 + 掩码 → 模型 → K 条候选 + 概率   → minADE20 / minFDE20
插补后预测（对照）：缺失历史 → 插补器 → 单条历史 → 预测器   → 单轨 ADE / FDE
```

两类口径的指标含义不同（best-of-K vs 单轨），只能分别标注报告，不得互相折算或声称"数值可直接比较"。

### 6.3 对照与消融设计（○ 待执行）

| 组 | 对照 | 回答的问题 |
|---|---|---|
| A | 缺失历史 + 零填充 / 前向填充 + 同一骨干 | 简单填充是否已解释全部收益 |
| B | 仅掩码拼接（M0 与 GAST-PF 现状） | 显式路由相比"把掩码当特征"多出什么 |
| C | 插补后预测（SAITS / BRITS 等外部插补器 + 同一解码器） | 串行插补路线在统一测试样本上的代价 |
| D | ECSR 逐落点递增：FrameGeo → +新鲜度门控 → +路径融合 → +读出 | 每个落点的独立贡献（单变量、配对重训） |
| E | 共享证据状态 vs 四个落点各自独立的控制器 | "统一路由"本身是否有效（而非模块堆叠） |
| F | 行为测试套件（§4.4 的 P1–P3 与其余必测项） | 机制是否真的按声明方式工作 |

纪律：每行只改一个主要因素；与对照共享同一初始 backbone state；报告 `missing_count=0` 子组作为首要证伪器（任何方法都不得在完整历史上退化）；单场景提升不足以支撑方法级结论，需多数主场景方向一致；进入主表前至少 3 个种子复验。

### 6.4 已确立的负结果（写入正文或附录的边界）

- **读出位置不是主要瓶颈**：把固定末端读出替换为"最后有效状态读出"（last-valid）在 Hard 场景出现局部正向、在 Easy 场景回归，收益未集中在 `valid_count=1` 或末端缺失样本。结论只能表述为"简单离散替换不是稳定方案"，ECSR 的读出因此采用连续条件化融合而非切换。
- **全局邻居可靠度偏置不成立**：以邻居有效帧比例作为 key 的全局注意力偏置隐含"历史越完整的邻居越值得关注"，该假设不成立——邻居是否有用取决于 focal–neighbor 的相对位置、相对运动与交互，而非邻居自身完整度。
- **零初始化不等于训练后隔离**：新分支初始为零只能保证初始前向接近基线；训练后共享参数仍会漂移，因此任何新模块必须单独报告 `missing_count=0` 子组。

## 7. 局限与边界

1. **证据等级**：GAST-PF 的五场景结果来自单种子、旧选点口径（checkpoint 按 `val_minFDE20` 选、test 由最终头产生），须按 `val_new_minFDE20` 重跑后才可进入定稿主表；ECSR 尚无五场景结果，本文只能声明其机制与可证伪设计，不声明其收益。
2. **缺失模型是受控而非真实**：TrajImpute 的缺失由"每轨迹均匀随机抽取 k∈{0..4} 或 {4..7} 帧、位置均匀散布"生成，属于机制性缺失（MCAR 近似），既不含第一视角的遮挡与视野边界导致的**位置依赖**缺失，也不含 ID switch、跟踪漂移与坐标噪声。本文结论不能直接外推到真实遮挡或安全规划；第一视角与 ego-view 噪声基准应作为独立扩展协议[9][10]。
3. **位置依赖分析仍是空白**：官方 release 的缺失位置在轨迹内近似均匀，因此"末端缺失更致命"这一假设无法从现有分层直接读出；需要自建按缺口位置分层的诊断（不改主协议），并同时报告可靠性指标（校准、覆盖率、spread）而非仅误差。
4. **对照完整性**：AgentFormer 仅完成 1/5 场景，其单场景数值不得当宏平均报告；外部强基线的 Clean 协议结果与本文 Mixed 协议不可直接比较。
5. **不做的事**：不建模地图与语义场景；不把隐藏表示解释为真实心理意图或物理状态；不以完整轨迹插补为最终目标；不联合建模定位噪声、误检与身份切换。

---

## 8. 结论

本文把行人轨迹预测从"完整历史"改写为"缺失历史观测"的条件预测问题，并给出两条互补的贡献：一个不做插补的直接预测协议 TrajGap-Bench（含五场景统一对照与缺失分层退化分析），以及一个以共享证据状态贯穿空间源资格、时序新鲜度、双向融合与历史读出的机制 ECSR。已完成的实验表明直接预测路线在缺失条件下可行且相对流匹配与经典基线具有竞争力，但骨干替换本身尚未带来稳定增益；因此本文的方法主张被有意收窄为三条可验证性质（全有效恒等、证据源不伪造、缺失年龄单调）与一套分层消融，而不是模块数量的堆叠。若 ECSR 在配对实验中不能同时满足高缺失子组改善与完整历史不退化，本文将收缩为"缺失历史下的系统性评估与失败边界"。
