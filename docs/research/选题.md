### 0.2 中文摘要草稿

真实检测与跟踪系统产生的行人轨迹历史普遍存在缺失。先插补再预测的串行方法将插补误差与未建模的不确定性传递给预测器；直接预测（direct forecasting）路线虽然绕开插补，但长期缺少统一评估基准——现有协议按难度拆成相互隔离的轨道，各自验证、各自选点，无法公平比较。本文工作由两部分组成。

**第一部分提出 TrajGap-Bench**：在 TrajImpute 官方缺失历史数据发布之上，于适配层将 Easy/Hard 按样本级合并为统一 Mixed 协议，训练、验证、测试同口径；以单一 Mixed 验证集上的最终预测头指标选择 checkpoint，杜绝按难度多次选点；在单一 Mixed 测试集上并列报告 `minADE20` / `minFDE20`（逐场景 + 五场景宏平均 + 样本加权平均 + 最差场景），不设综合分数。该基准提供无泄漏的固定协议、可复现的 8→12 帧任务与参考实现。

**第二部分构建 GAST-PF-HER（Gap-Aware Spatio-Temporal Pedestrian Forecaster with Hierarchical Evidence Reasoning）缺失历史行人轨迹预测框架**：针对观测历史不完整造成的运动信息断裂、行人关系不充分、时间状态退化与末端读出偏差，整合逐帧相对几何关系建模、单向 gap-aware Mamba、缺失感知历史读出、编码后场景交互和多模态未来分布解码。共享层级证据状态为各阶段提供统一的缺失信息表征，并参与关系更新、时序输入、历史聚合和场景上下文融合。整体框架在 TrajGap-Bench 上采用一致协议评估，结合递进消融与缺失分层分析检验整体表现及关键组件的作用；模型对照实验仍在补齐。

### 0.3 English Abstract (Draft)

Pedestrian trajectories observed in the wild routinely contain missing histories caused by occlusion, tracker failures, and sensor dropouts. Impute-then-predict pipelines propagate imputation errors to the forecaster, while direct forecasting — consuming the masked history as-is — has lacked a shared benchmark: existing protocols fragment conditions into isolated difficulty tracks with per-track validation and no common leaderboard.

This work contributes along two axes. **First, TrajGap-Bench**: built on the official TrajImpute release, it merges Easy and Hard splits sample-wise into a single Mixed protocol for training, validation, and testing; selects checkpoints by one final-head metric on one Mixed validation set; and reports `minADE20` / `minFDE20` side by side (per-scene, macro, sample-weighted, worst-scene) with no composite score. **Second, GAST-PF-HER**, an end-to-end framework for pedestrian trajectory forecasting from incomplete histories: it combines frame-wise relative-geometry interaction, causal gap-aware Mamba encoding, missingness-aware history readout, post-temporal scene interaction, and multimodal future-distribution decoding. A shared hierarchical evidence representation connects these stages and informs how historical states and social context are used. The complete framework is evaluated under the TrajGap-Bench protocol, with progressive ablations and missingness-stratified analyses designed to assess overall performance and component contributions; matched model comparisons are in progress.

## 1. 研究背景与问题提出

### 1.1 两部分工作的整体关系

本文由相互支撑的基准与方法两部分构成：

```text
贡献 A（TrajGap-Bench）：建立统一任务协议与可比较的评测基础
        │  固定 Mixed 协议 + checkpoint 选择 + 多维度结果报告
        ├──────────────────────────────┐
        ▼                              ▼
刻画不同缺失条件下的模型表现    贡献 B（GAST-PF-HER）：构建任务适配的完整预测框架
                                       │
                   几何关系 + 时序建模 + 历史读出 + 场景交互 + 多模态预测
```

TrajGap-Bench 为不同预测方法提供统一的数据协议和比较口径；GAST-PF-HER 则针对不完整历史下的空间、时间与场景信息建模提出完整方法设计。基准支撑模型的公平评估，模型实验也反过来展示该基准对方法研究的用途，两者共同构成论文的研究闭环。

### 1.2 背景一：直接预测缺少统一基准

真实行人轨迹常因遮挡、跟踪丢失、传感器中断出现历史缺口。处理路线有二：

- **先插补后预测**：先重建缺失坐标再预测，插补值与真实观测的差异通常不被下游显式区分，单值插补还可能低估缺失不确定性 [5, 12, 13]；
- **直接预测**：直接消费带掩码历史，基于实际可用证据预测。插补本身会引入误差，且只有能感知*可用证据的数量与排布*的模型，才能在观测逐渐减少时优雅退化。

直接预测路线此前缺少共享基准：TrajImpute 官方协议把条件拆成 Easy / Hard 两条相互隔离的轨道，各自验证、无统一榜单、无统一 checkpoint 选择规则 [5]；经典 ETH/UCY 基准则假设历史完整。两个社区之间没有一座固定的桥。

### 1.3 背景二：缺失历史下的时空预测建模问题

直接消费带掩码历史避免了显式插补误差，但模型仍需处理多个相互关联的问题：

1. 不规则缺失打断位移与速度序列，使运动状态编码更依赖剩余有效观测；
2. 单帧输入特征未必充分表达行人间相对位置、相对运动与方向关系；
3. 个体时间编码需要兼顾因果时序建模和缺失间隔造成的状态陈旧；
4. 末端缺失会使固定末帧读出偏离最近的有效历史状态；
5. 场景交互需要利用邻居上下文，同时处理各 actor 历史完整程度不同的情况。

因此，研究问题不局限于某一种门控或路由方式，而是如何把空间关系、个体时间演化、有效历史读出与群体场景交互组织成适用于缺失历史的端到端预测流程。观测有效性、缺失年龄和可靠度为这些环节提供共享的任务状态表示，其具体作用由分层实验检验。

### 1.4 核心研究问题

**问题 A（基准）**：如何在不动数据、不重切窗口、不引入泄漏的前提下，把缺失历史直接预测组织成一个选点唯一、口径统一、可直接比较的基准？

**问题 B（模型）**：在不先插补完整历史的条件下，如何联合建模缺失历史中的相对几何、个体时序、末端有效状态和社会交互，从而直接生成准确且多模态的未来行人轨迹？

## 2. 主贡献与边界

### 2.1 贡献 A：TrajGap-Bench（基准贡献）

> **在 TrajImpute 官方发布之上，为直接缺失历史预测定义统一 Mixed 协议：样本级合并、单一验证选点、双主指标并列榜单、无综合分，并给出参考实现与基线。**

具体产出：

1. **统一协议**：Easy/Hard 同一 split 按样本级合并为 Mixed，训练、验证、测试同口径；
2. **单一验证**：一个 Mixed 验证集、按最终预测头 `val_new_minFDE20` 选 checkpoint——不按难度分别选点，不用测试集调参；
3. **单一榜单**：一个 Mixed 测试集，K=20 下并列报告 `minADE20` / `minFDE20`，含逐场景、五场景宏平均、样本加权 micro 平均与最差场景，不定义综合分数；
4. **工程载体**：`TrajGapDataset` 适配器（确定性修复上游 `seq_start_end` bug，官方文件只读）、direct 评估器（六维缺失分层）、榜单生成器（从 `results.json` 现算生成，禁止手抄）；
5. **提交清单**：任何新方法进入榜单的五个准入条件（§4.6）。

### 2.2 贡献 B：GAST-PF-HER（模型贡献）

> **面向缺失历史行人轨迹预测，构建 GAST-PF-HER 时空建模框架，将逐帧几何关系建模、因果时序编码、缺失感知历史读出、编码后场景交互与多模态未来预测整合为完整流程；共享层级证据状态用于协调各阶段对不完整历史及邻居上下文的利用。**

该贡献覆盖从历史输入表征到未来分布输出的整体预测过程。论文应说明各设计分别应对的任务困难、模块间表示衔接方式，以及完整框架相对于基线的实测增益；共享证据状态是连接多个阶段的关键设计之一，但不替代对完整时空预测方法的介绍。

### 2.3 方法组成与论文表述

GAST-PF-HER 作为一个整体方法提出与评估，不把常用算子或每个网络层单独拆成贡献。论文中应在相关工作与方法介绍中引用 GSM、ghost token、Temporal Decay/BTS、Mamba、社会交互预测和多模态预测等对应研究 [1, 2, 9, 10]，再具体说明它们在本任务中的输入、几何条件、缺失状态、时间方向、读出方式和阶段接口如何组织。对于模型组合产生的有效性或特定缺失条件下的收益，只在完成匹配对照与分层实验后作出结论。TrajGap-Bench 对上游数据资源的使用与本文新增的 direct Mixed 协议仍需分别说明。

## 3. 相关工作定位

### 3.1 缺失历史轨迹预测与基准

缺失轨迹研究包括联合插补与预测、插补后预测和直接使用不完整历史三类。GC-VRNN、MS-TIP 与 TrajImpute 代表缺失轨迹恢复、联合建模或基准构建方向 [3–5]；允许不完整输入的时空图方法更接近本文 direct 设定 [6]。**定位边界**：TrajImpute 建立了缺失历史数据资源与插补后预测协议 [5]；TrajGap-Bench 贡献 direct 侧缺失的统一协议，属于**派生基准**（derived benchmark）——不重新主张上游数据贡献，官方插补后预测数字不与 direct 结果同榜。

### 3.2 观测长度、末端缺失与不确定性

瞬时观测、变长观测和感知不确定性研究说明，观测数量、位置和质量都影响未来预测 [7, 8, 11–13]。本文将这些因素统一压缩为任务内的证据状态，但不把 age-based reliability 解释为已校准的概率置信度；若论文讨论 calibration / NLL / coverage，须增加独立的不确定性实验。

### 3.3 缺失感知时序建模与 Mamba

Mamba、GSM、ghost token 与 Temporal Decay 等设计已有相应轨迹预测与序列建模研究 [9, 10]。本文在相关工作中说明这些设计及其适用背景，并在方法部分阐述 GAST-PF-HER 如何将逐帧关系建模、单向因果时间聚合、缺失感知读出和编码后场景交互组织为缺失历史预测流程；层级证据状态是跨阶段输入信息的一种统一表达。论文的差异与贡献应由具体实现和对照实验说明。

### 3.4 社会交互建模

Social LSTM、AgentFormer 等方法展示了 actor-level 社会交互对轨迹预测的作用 [1, 2]。在缺失历史设定下，场景交互还需要面对各行人历史长度与完整程度不同的问题。GAST-PF-HER 将编码后的 actor 表示、场景上下文、位置/方向几何和观测状态共同纳入预测流程。MoFlow [14] 作为完整历史设定下的生成式外部基线进入榜单参照，不与 direct 口径混同。

## 4. 贡献 A：TrajGap-Bench

### 4.1 基准身份审计（四层）

| 层 | 内容 | 状态 |
|---|---|---|
| 1. Source release 数据来源 | TrajImpute 官方发布：5 场景 × Easy/Hard × train/val/test，共 30 个 pickle，缺失处 `NaN` 且与 `missing_mask` 严格一致，未来恒完整 | 上游贡献，只读复用 |
| 2. Task definition 任务定义 | 直接（无外部插补）缺失历史预测：8 帧带掩码历史 → 12 帧完整未来，每样本至少 1 个有效历史帧，K=20 | 本文定义 |
| 3. Adaptation protocol 适配协议 | Easy+Hard 同一 split 按样本级合并为 Mixed；单一 Mixed-val 选点；确定性重建 `seq_start_end`；不重切窗、不去重、不重采样 | 本文定义 |
| 4. Evaluator & results 评估与榜单 | direct 评估器（六维缺失分层）+ 榜单生成器；`minADE20`/`minFDE20` 并列，宏平均 + micro + 最差场景 | 本文实现 |

**定位声明**：TrajGap-Bench 是建立在 TrajImpute 数据发布之上的派生基准。上游贡献数据资源与插补后预测协议；本文贡献 direct 任务的统一口径。两者输入信息不同，数字永不同榜。

### 4.2 任务数学定义

设场景包含 \(N\) 个 actor，观测长度 \(T=8\)，预测长度 \(H=12\)。actor \(i\) 在时刻 \(t\) 的历史位置为 \(\mathbf{p}_{i,t}\in\mathbb{R}^{2}\)，有效性掩码 \(m_{i,t}\in\{0,1\}\)；\(m_{i,t}=0\) 时输入中的占位位置不视为直接观测。每个样本至少保留一个有效历史帧。

模型输出 focal actor 的 K 模态未来分布：

\[
\hat{\mathcal{Y}}=\left\{(\hat{\mathbf{y}}^{(k)},\pi_k)\right\}_{k=1}^{K},\qquad \sum_{k=1}^{K}\pi_k=1,
\]

其中 \(\hat{\mathbf{y}}^{(k)}\in\mathbb{R}^{H\times2}\)，\(\pi_k\) 为模式概率，\(K=20\)。**直接约束**：方法必须直接消费带掩码历史；模型内部将插补作为隐式机制允许，但预测前依赖外部现成插补模块的方法单独评估、不进本榜单。预测目标是未来轨迹，不是历史插补误差最小化。

### 4.3 数据集构造

对每个场景与每个 split：

```text
TrajGap(scene, split) = TrajImpute(scene, Easy, split) + TrajImpute(scene, Hard, split)
```

`+` 为 actor-centric 样本级拼接；来源标签保留供内部审计，对外协议名统一 **Mixed**。Mixed 训练集缺失程度覆盖 m=0…7（Easy 供 0–4，Hard 供 4–7），约 10% 训练样本历史完整。

**Focal 样本统计（已对官方文件审计）**：

| 场景 | Mixed train | Mixed val | Mixed test |
|---|---:|---:|---:|
| ETH-M | 59,618 | 10,698 | 1,629 |
| HOTEL-M | 58,304 | 10,272 | 9,477 |
| UNIV-M | 18,462 | 5,416 | 219,006 |
| ZARA1-M | 56,020 | 10,236 | 20,277 |
| ZARA2-M | 51,014 | 8,346 | 52,497 |
| **合计** | **243,418** | **44,968** | **302,886** |

### 4.4 评估协议

## 5. 贡献 B：GAST-PF-HER 时空预测框架

### 5.1 方法总览

```text
历史运动特征 + 有效性掩码 + 原始历史位置
                         ↓
             共享观测证据状态 (s, a, r)
                         ↓
       逐帧几何关系建模与 GSM 交互
                         ↓
             可靠度调制的单向 Mamba
                         ↓
             可靠度加权历史证据读出
                         ↓
       缺失感知编码后 Scene Tail
                         ↓
             FutureDistributionDecoder
                         ↓
                    K 个未来模式
```

该完整流程包含四个相互衔接的建模阶段：**逐帧空间关系阶段**利用同一时刻各行人的运动与相对几何；**个体时序阶段**以单向 Mamba 建模因果演化，并用观测年龄调节历史状态的作用；**历史读出与场景阶段**根据末端有效性汇聚个体历史，再让 actor-level Scene Tail 融合邻居上下文；**未来生成阶段**使用既有多模态预测解码器输出 K 个候选轨迹。观测证据状态连接前述阶段，但论文方法介绍应覆盖从输入到输出的整个预测框架。

### 5.2 输入字段与信息边界

GAST-PF 基础逐帧历史特征为 4 维：

\[
\mathbf{x}^{hist}_{i,t}=[\Delta\mathbf{p}_{i,t},\Delta v_{i,t},m_{i,t}]\in\mathbb{R}^{4}.
\]

HER 另使用：原始历史位置 `x_positions`（有效观测 actor 间相对几何）、`x_centers`（最后有效位置）、`x_last_valid_angle`（最后有效方向）、`x_key_valid_mask`（padding 区分）、actor 类型。因此"基础输入只有 4 维"与"模型只使用 4 维信息"不是同一命题。

### 5.3 共享观测证据状态

对每个 actor 与时间步定义 \(\mathbf{e}_{i,t}=(s_{i,t},a_{i,t},r_{i,t})\)：直接观测资格、缺失年龄、软可靠度。设 \(\ell_{i,t}\) 为不晚于 \(t\) 的最近有效观测位置，则

\[
a_{i,t}=t-\ell_{i,t},\qquad
r_{i,t}=\begin{cases}1,&m_{i,t}=1,\\ \exp(-\tau a_{i,t}),&m_{i,t}=0,\end{cases}
\]

其中 \(\tau=\operatorname{softplus}(\theta_\tau)>0\) 为可学习衰减率；无任何有效观测时 \(a_{i,t}=t+1\)；padding actor 证据状态无效。**该可靠度是由 mask 与年龄解析得到的任务内代理量，不是校准概率置信度，也不估计检测噪声、遮挡成因或身份切换。**

### 5.4 逐帧关系证据收集

GSM 对每个历史帧做 actor 级自注意力并拼接 ghost token。ECHR 使用直接观测资格控制 source：ghost 始终可用，actor \(j\) 仅当 \(s_{j,t}=1\) 且非 padding 时才是有效 source。对有效 actor 对构造 7 维几何特征

\[
\boldsymbol{\phi}_{ij,t}=[\Delta x,\Delta y,\log(1+\|\Delta\mathbf{p}\|),\Delta v_x,\Delta v_y,\cos\Delta\psi,\sin\Delta\psi],
\]

经小型 MLP 为每个注意力头生成加性 bias（末层零初始化）。**严格区分两种操作**：source eligibility 作用于 attention key/source；query reliability 作用于 GSM 输出之后（\(\tilde{z}_{i,t}=r_{i,t}z_{i,t}^{GSM}\)）。当前实现未把可靠度加入 query logits，论文不得描述为 query-logit routing。

### 5.5 单向 gap-aware Mamba 与证据读出

逐帧表示经 MLP 后按可靠度缩放进入单向 Mamba：

\[
u_{i,t}=r_{i,t}\operatorname{MLP}(\tilde{z}_{i,t}),\qquad
h_{i,1:T}=\operatorname{Mamba}_{\rightarrow}(u_{i,1:T}).
\]

这是输入幅度调制，不改 Mamba 内部状态转移，不跳过缺失时刻的状态更新；单向栈保证 \(h_{i,t}\) 不依赖未来历史位置。末端读出使用可靠度加权历史证据：

\[
w_{i,t}=\operatorname{softmax}_t(q_{i,t}+\beta\log(r_{i,t}+\epsilon)),\qquad
a_i=r_{i,T}h_{i,T}+(1-r_{i,T})\sum_t w_{i,t}h_{i,t}.
\]

末端有效时严格回到末帧状态；末端缺失时历史证据占比升高。不是简单 last-valid 拷贝。

### 5.6 证据条件化 Scene Tail

actor token 与最后有效位置、方向、类型嵌入组合为场景 token，经 M0 原有 5 层 Scene Transformer 交互。对 key actor \(j\) 加可靠度偏置 \(b^{key}_{ij}=\log(\max(r_{j,T},10^{-4}))\)；对 query actor 计算证据融合门

\[
g_i=\sigma\left(f_g([r_{i,T},\operatorname{clip}(a_{i,T}/(T-1),0,1)])\right),\qquad
a_i^{out}=a_i+\alpha_{scene}g_i(\operatorname{SceneTail}(v)_i-a_i).
\]

\(\alpha_{scene}\) 从 0 初始化，训练起始不扰动 actor token。该尾部恢复 M0 的编码后场景推理，不恢复 M0 的历史投影与历史 Mamba。

### 5.7 预测头、损失与固定接口

HER 后接原有 `FutureDistributionDecoder`；预测头、loss、优化器、数据切分与主评估接口不变。不引入未来编码器、CVAE 潜变量、辅助历史重建损失或新的概率校准头，以避免将编码器路由收益与训练目标变化混淆。

## 6. 研究假设与实验设计

### 6.1 可检验假设

- **H1：几何关系建模。** 相对位置、相对运动和方向信息可补充基础位移差分，改善缺失历史条件下的逐帧行人关系表示。
- **H2：因果时间建模与历史读出。** 单向 Mamba 与缺失感知历史读出可更合理地利用不完整历史，尤其是在末端缺失或长连续缺失条件下。
- **H3：场景上下文整合。** 编码后 Scene Tail 能在逐帧交互之外补充 actor-level 场景推理；证据条件化尾部是否进一步有益，由其与普通尾部的配对实验判断。
- **H4：整体方法的互补性。** 几何、时间、读出与场景交互组合后，应在统一协议下改善总体预测表现，且不以显著损害完整历史子组为代价。

### 6.2 主对照与递进消融（同口径）

| 变体 / 设置 | 相对比较 | 回答的问题 |
|---|---|---|
| `GAST-PF-Uni` | `GAST-PF` → 单向 Mamba | 时序方向改变对历史建模有何影响？ |
| `GAST-PF-UniTail` | `Uni` → 普通 Scene Tail | 编码后场景交互能否补充逐帧关系建模？ |
| `Uni + FrameGeo` | `Uni` → `gast_frame_geo` | 逐帧相对位置输入能否补足运动差分表示？ |
| `GAST-PF-UniOER` | `Uni` → 缺失感知空间、时间与读出路径 | 整合几何与缺失处理后，编码路径整体如何变化？ |
| `GAST-PF-UniOER-Tail` | `UniOER` → 普通 Scene Tail | 普通场景尾部对缺失感知编码表示的增量是什么？ |
| `GAST-PF-HER` | `UniOER-Tail` → 证据条件化 Scene Tail | 场景交互是否需要根据观测状态调节？ |

`Uni` 到 `UniOER` 同时涉及空间关系、时序输入和历史读出，解释为编码路径整体差异，不单独归因于某一子机制。HER 相对 `UniOER-Tail` 同时含 GSM query 表示调节、Scene Tail key bias 与融合门；若需报告单一机制的因果贡献，应在主对照通过后追加对应定向消融。

### 6.3 训练与公平比较

- 固定 TrajGap-Bench Mixed-direct 协议、split、预测头、loss、优化器、训练预算与选点规则；
- 筛选配置：seed=2024、100 epochs、batch 64、K=20、`lr=1e-3`、`weight_decay=1e-4`、bf16-mixed、`val_new_minFDE20` 选点；正式论文以 manifest 逐项复核；
- 报告参数量、显存、训练时间与推理延迟；单向模型少一套反向 Mamba 参数，不能把参数减少的收益全部解释为结构优势；
- 新增模块零初始化/配对初始化；checkpoint 的方向、开关、模式数与评估变体严格匹配（fail-closed 校验）。

### 6.4 指标与分层

主指标：五场景宏平均 `minADE20` / `minFDE20`（并报 micro）。辅助：`ADE@1` / `FDE@1`（排序质量诊断，与 best-of-20 分开解释）。必须分层：`missing_count`、`valid_count`、`terminal_missing`、`anchor_lag`、`forecast_gap`、最长连续缺失长度、focal-邻居可用性组合；每子组报样本数。不得只挑收益最大的场景或缺失档位。

### 6.5 机制诊断（主筛选通过后）

可学习衰减率 \(\tau\) 与年龄-可靠度分布、GSM source 覆盖率、Scene Tail key bias、融合门 \(g_i\) 分布、\(\alpha_{scene}\) 训练轨迹、全有效/末端缺失/长缺失组的门控差异。诊断只说明模型是否按预期使用证据，因果结论仍依赖配对重训消融。

### 6.6 预先判定规则

1. **支持整体框架**：五场景同口径优于有代表性的基线与结构匹配变体，收益不由单一场景主导，并在预先定义的缺失分层中得到支持；
2. **部分支持**：仅 `UniTail` 有效 → 将结论收窄为编码后场景交互的增量；仅 `Uni + FrameGeo` 有效 → 将结论收窄为几何输入的增量；编码路径有效但 HER 无增益 → 不声称证据条件化尾部必要；
3. **不支持特定缺失机制解释**：整体指标改善但末端/长缺失组没有相应变化时，不将总体改善归因为缺失状态处理；
4. **停止叠加**：完整模型不优于结构匹配对照或不可复现 → 停止加模块，记录负结果，回到实现审计；后撤版题目（§0.1）生效。

## 9. 局限与不应过度声称的内容

1. 当前 reliability 只由有效性与缺失年龄构造，不能区分遮挡、漏检、异步采样、坐标噪声与 ID switch；
2. GSM 的 query reliability 是注意力后的表示门控，不是 query-logit routing；
3. Scene Tail key bias 在 actor 级末端使用可靠度，不等于每条 pairwise interaction 都有可解释因果权重；
4. 单向 Mamba 的因果编码不自动等于在线部署优势；声称实时性须补缓存、延迟与吞吐实验；
5. TrajGap-Bench 的受控缺失机制不能直接代表真实遮挡、跟踪漂移或视野边界缺失；测试集含按缺失程度复制的重复轨迹；
6. TrajGap-Bench 是派生基准，上游数据与插补协议的贡献属于 TrajImpute，不得重复主张；
7. 若 HER 只在少数场景、单 seed 或特定训练预算下有效，结论必须收缩；单 seed 结果是初步观察，不进正式结论。
